## 总则

一秋小镇致力于为所有玩家提供一个公平、友善、纯粹的原版生存环境。以下是服务器的基本规则，所有玩家在进入服务器后即视为已阅读并同意遵守以下条款。管理员有权根据实际情况对规则进行解释和调整，请关注服务器公告以获取最新信息。

## 核心规则

### 1. 禁止作弊

服务器安装了 **GrimAC** 反作弊系统，任何形式的作弊行为都将被自动检测并处罚。作弊行为包括但不限于：

- 使用飞行、加速、自动挖掘等作弊客户端或模组
- 利用游戏 Bug 获取不正当优势（发现 Bug 请主动报告管理员）
- 使用连点器、宏等外设辅助工具进行自动化操作
- 任何其他破坏游戏公平性的行为

### 2. 禁止恶意破坏

一秋小镇是原版生存服务器，请尊重其他玩家的劳动成果。以下行为严格禁止：

- 未经允许破坏或偷取他人领地内的方块和物品
- 故意在他人建筑周围制造混乱（如大量放置岩浆、水等）
- 利用游戏机制恶意干扰他人游戏体验
- 大面积破坏自然地形（如过度砍伐公共区域树木而不补种）

### 3. 领地与资源

- 使用 **Dominion** 领地系统保护你的建筑和区域，领地内受到完整保护
- 公共资源（如公共农场、公共矿道）请合理使用，不要垄断或浪费
- 请勿在他人领地边界恶意搭建或制造噪音性红石装置
- 资源采集建议远离 Spawn 区域和他人领地

### 4. 聊天与社交

- 禁止在聊天频道发布广告、刷屏、辱骂或其他骚扰行为
- 禁止讨论政治、宗教等敏感话题
- 请使用文明用语，尊重每一位玩家
- 禁止冒充管理员或官方人员
- 建议使用 **FairyChat** 聊天系统的频道功能，将不同话题分流到对应频道

### 5. 红石与生电

- 鼓励建设红石机械和自动化装置，这是服务器的核心玩法之一
- 请确保你的红石装置**不会严重影响服务器性能**（如超大规模高频红石时钟）
- 如果你的装置可能导致 TPS 下降，管理员会联系你进行优化
- 请勿建造恶意装置（如针对特定玩家的陷阱、陷阱箱等）

### 6. 商店与经济

- **QuickShop** 玩家商店交易应诚实守信，禁止欺诈行为
- 禁止利用经济系统 Bug 进行刷钱或物品复制
- 商店定价应合理，禁止恶意垄断市场
- 使用 **UltimateShop** 全局商店时，请遵守系统规则

## 玩家行为准则

### 鼓励的行为

- 协作建设大型红石项目
- 分享生电设计和建筑技巧
- 帮助新手玩家适应服务器
- 主动报告发现的 Bug
- 参与社区活动和讨论

### 禁止的行为

- 任何形式的歧视（性别、种族、地域等）
- 恶意 PVP（除非双方同意）
- 传播不实信息或恶意造谣
- 多开账号刷奖励
- 利用服务器机制漏洞牟利

## 处罚措施

| 违规等级 | 行为举例 | 处罚方式 |
|----------|----------|----------|
| 轻度 | 首次轻微违规、聊天不当 | 口头警告 |
| 中度 | 恶意破坏、重复违规 | 临时封禁（1~7 天） |
| 重度 | 作弊、严重破坏、欺诈 | 永久封禁 |

> [!WARNING]
> 处罚措施由管理员根据实际情况裁定。对于严重违规行为，管理员有权直接实施永久封禁而不经过警告。

## 免责声明

- 管理员不对玩家个人数据的意外丢失承担责任，请定期使用 `/home` 等命令保护重要物品
- 服务器可能会进行不定期维护和更新，届时可能影响正常游戏
- 规则的最终解释权归服务器管理团队所有

如对规则有任何疑问，请在服务器内联系管理员或在社区渠道反馈。
