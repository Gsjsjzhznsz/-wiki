## 欢迎加入一秋小镇

一秋小镇是一个纯原版生存生电服务器，致力于为玩家提供流畅、稳定、公平的游戏环境。本指南将帮助你从零开始，快速融入服务器社区。无论你是 Minecraft 老玩家还是刚入坑的新手，这里都有适合你的玩法空间。

## 第一步：准备客户端

一秋小镇支持极为广泛的客户端版本，你需要确保使用以下任一版本即可正常加入服务器：

### Java 版

| 版本范围 | 说明 |
|----------|------|
| 1.7.x ~ 1.20.4 | 通过 ViaVersion + ViaBackwards 自动适配 |
| 1.20.5+ | 原生支持，无需额外协议转换 |
| 最新 26.2 | 完全兼容 |

> [!TIP]
> 推荐使用 **1.21.x** 或更高版本以获得最佳体验，该版本范围内为服务器主版本，所有功能测试最完善。

### 基岩版（BE）

- 支持 **Bedrock Edition**（手机端、Win10/11、Switch、PS、Xbox 等）
- 推荐使用**最新正式版**客户端
- 通过 Geyser 插件实现与 Java 版的无缝互通
- 基岩版玩家可以与 Java 版玩家在同一世界互动、交易、组队

## 第二步：添加服务器

### Java 版添加方式

1. 打开 Minecraft Java 版，选择**多人游戏**
2. 点击**添加服务器**
3. 填写以下信息：
   - **服务器地址**：`mysv.dpdns.org`
   - **服务器名称**（可选）：`一秋小镇`
4. 点击**完成**，然后选择该服务器并点击**加入服务器**

### 基岩版添加方式

1. 打开 Minecraft 基岩版，选择**游戏** > **服务器**
2. 滚动到底部，点击**添加服务器**
3. 填写以下信息：
   - **服务器地址**：`be.mysv.dpdns.org`
   - **端口**：`19131`
   - **服务器名称**（可选）：`一秋小镇`
4. 点击**保存**，然后选择该服务器并加入

> [!NOTE]
> 如果主地址无法连接，可以使用备用地址 `frp-oak.com:58016`，IPv6 用户可直连 `ipv6.mysv.dpdns.org:19132`。

## 第三步：首次登录

### Java 版玩家

1. 首次进入服务器后，系统会提示你使用 `/register <密码> <确认密码>` 注册账户
2. 之后每次登录使用 `/login <密码>` 验证身份
3. 认证通过后即可自由游玩

### 基岩版玩家

1. 基岩版通过 Geyser 互通，会自动使用你的 Xbox Live 账户进行认证
2. 首次进入可能需要额外注册绑定，请按照服务器内提示操作
3. 如遇到皮肤显示问题，服务器已安装 SkinsRestorer 自动修复

## 第四步：新手必做

完成登录后，建议你按顺序完成以下操作：

1. **查看规则**：使用 `/rules` 或阅读 [服务器规则](/guide/rules/) 页面，了解服务器规范
2. **设置家园**：找到一个你喜欢的位置，使用 `/sethome <名称>` 设置你的家
3. **圈地保护**：使用 Dominion 领地系统圈定你的领地，防止物品被破坏或窃取
4. **探索商店**：访问服务器商店购买初始物资，或自己采集资源起步
5. **使用签到**：每天签到获取奖励，积累资源

## 常用命令速查

| 命令 | 说明 |
|------|------|
| `/register <密码> <确认>` | 注册账户 |
| `/login <密码>` | 登录账户 |
| `/sethome <名称>` | 设置家园 |
| `/home <名称>` | 传送到家园 |
| `/tpa <玩家>` | 请求传送到其他玩家 |
| `/spawn` | 回到出生点 |
| `/warp <名称>` | 传送到地标点 |
| `/sign` 或 `/签到` | 每日签到 |
| `/balance` 或 `/bal` | 查看余额 |
| `/shop` | 打开商店 |

## 遇到问题？

如果以上步骤中遇到任何问题，可以通过以下方式获取帮助：

- 在服务器内使用 `/help` 查看命令帮助
- 阅读本 Wiki 中对应插件的详细文档
- 联系服务器管理员寻求协助
