## 服务器接入地址

一秋小镇提供多种接入方式，覆盖 Java 版和基岩版，支持 IPv4 和 IPv6 直连。无论你使用何种客户端，都可以找到适合的连接方式。服务器通过 Via 系列协议库实现全版本自动适配，你无需担心版本兼容问题。

## 接入地址一览

| 接入端 | 地址 | 端口 | 说明 |
|--------|------|------|------|
| **Java 版（主）** | `mysv.dpdns.org` | 默认（25565） | 推荐首选，DDNS 自动解析 |
| **Java 版（备用）** | `frp-oak.com` | 58016 | 主地址不通时使用，FRP 内网穿透 |
| **基岩版（BE）** | `be.mysv.dpdns.org` | 19131 | 手机/Win10/主机端专用 |
| **IPv6 直连** | `ipv6.mysv.dpdns.org` | 19131 | 支持 IPv6 的网络环境 |

## Java 版接入

### 支持的版本范围

一秋小镇通过 **ViaVersion + ViaBackwards + ViaRewind** 实现了极为广泛的版本兼容。以下是各版本段的兼容情况：

| 版本范围 | 兼容方式 | 体验说明 |
|----------|----------|----------|
| 1.7.x ~ 1.12.2 | ViaRewind + ViaBackwards | 基础玩法完整，部分新方块显示为旧版方块 |
| 1.13.x ~ 1.19.4 | ViaBackwards | 大部分功能正常，新版生物/方块可能有限制 |
| 1.20.x | 原生 / ViaBackwards | 完整体验，推荐使用 |
| 1.21.x ~ 26.2 | 原生支持 | 最佳体验，所有功能完全可用 |

### 添加服务器步骤

1. 打开 Minecraft Java 版主菜单
2. 选择 **多人游戏** → **添加服务器**
3. 服务器地址填写：`mysv.dpdns.org`
4. 点击 **完成**，双击服务器名称即可加入

### 版本选择建议

- **追求最佳体验**：使用服务器当前运行的 Minecraft 主版本（建议 1.21.x+）
- **老版本情怀**：1.12.2 等经典版本可正常游玩，但部分新内容无法体验
- **不确定用哪个**：随便选一个你能用的版本，Via 系列会自动处理协议转换

> [!WARNING]
> 使用 1.7.x 等极旧版本时，部分新方块、新物品的显示可能出现异常，这是协议转换的已知限制，属于正常现象。

## 基岩版（BE）接入

### 基岩版互通原理

一秋小镇通过 **Geyser-Spigot** 插件实现基岩版与 Java 版的无缝互通。Geyser 会将基岩版的网络协议实时翻译为 Java 版协议，使基岩版玩家能够与 Java 版玩家在同一世界中互动。

### 支持的基岩版平台

- **手机端**：iOS / Android
- **主机端**：Nintendo Switch / PlayStation / Xbox
- **Windows 10/11**：Minecraft for Windows（Bedrock Edition）

### 添加服务器步骤

1. 打开 Minecraft 基岩版
2. 进入 **游戏** → **服务器** 选项卡
3. 滚动到底部，点击 **添加服务器**
4. 填写信息：
   - **服务器名称**：`一秋小镇`（可自定义）
   - **服务器地址**：`be.mysv.dpdns.org`
   - **端口**：`19131`
5. 保存后选择服务器并点击加入

### 基岩版已知限制

| 功能 | 状态 | 说明 |
|------|------|------|
| 基础生存 | 正常 | 采集、合成、建造完全可用 |
| 红石机械 | 基本正常 | 复杂红石电路可能有微小差异 |
| 聊天系统 | 正常 | 可与 Java 版玩家互通消息 |
| 皮肤显示 | 自动修复 | SkinsRestorer 处理跨端皮肤 |
| 部分自定义物品 | 可能受限 | NBT 复杂物品在 BE 端可能显示异常 |

## IPv6 直连

如果你的网络环境支持 IPv6（如教育网、部分运营商），可以通过 IPv6 地址直连服务器，通常可以获得更低的延迟和更稳定的连接：

- **地址**：`ipv6.mysv.dpdns.org`
- **端口**：`19131`

> [!TIP]
> 可以使用 [IPv6 测试网站](https://test-ipv6.com/) 检查你的网络是否支持 IPv6。如果支持，IPv6 直连通常是更快的选择。

## 连接故障排除

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 无法解析地址 | DNS 问题 | 使用备用地址 `frp-oak.com:58016` |
| 连接超时 | 网络问题 / 防火墙 | 检查网络连接，尝试切换 Wi-Fi/有线 |
| 版本不兼容 | 版本过低 | 服务器支持 1.7+，确保不在更旧版本 |
| 登录失败 | AuthMe 未注册 | 先使用 `/register` 注册账户 |
| 基岩版加入失败 | Geyser 问题 | 确保使用最新基岩版客户端 |
| 皮肤显示错误 | 跨端皮肤同步 | SkinsRestorer 会自动处理，重新登录即可 |

如果以上方法均无法解决你的问题，请联系服务器管理员获取进一步帮助。
