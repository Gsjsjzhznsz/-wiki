## 一秋小镇 — 你的工业帝国起点

一秋小镇是一个聚焦**原版生存与红石科技**的 Minecraft 社区服务器。我们基于 **Folia 多线程架构**深度优化，搭载完整的 **Via 系列协议兼容**与 **Geyser 基岩版互通**，为 Java 1.7~26.2 和基岩版玩家提供一致的原版生存体验。

服务器秉承**轻量化插件**理念——仅保留必要功能，无花哨 RPG 或付费特权干扰核心玩法，让每一位玩家都能专注于创造与探索。

## 为什么选择一秋小镇？

**技术底子硬** — Folia 多线程 + 协议层全兼容，拒绝卡顿与版本冲突，即使在大型红石机械或百人同屏场景下，服务器时钟依然稳定在 20.0 TPS。全版本协议自动适配，无论你使用 Java 1.7 的老客户端还是最新的 26.2 版本，亦或是基岩版手机端，都能获得一致的游戏体验。

**生电氛围纯** — 没有魔改合成表干扰你的红石设计，没有强制付费破坏游戏平衡，所有插件均服务于生存便利，绝不喧宾夺主。服务器鼓励玩家协作搭建自动化工厂、物品分类仓储、远程运输网络，打造属于自己的工业帝国。

**社区友善** — 插件功能"用完即走"，不干扰核心生存体验，新手老手皆可融入。完善的领地保护、反作弊系统和账户安全机制，让每一位玩家都能安心享受游戏乐趣。

**持续更新** — 服务器持续迭代更新，AutoViaUpdater 自动升级协议库，GeyserUpdater 保持基岩版互通最新，玩法由玩家定义——我们只提供最稳定的舞台。
