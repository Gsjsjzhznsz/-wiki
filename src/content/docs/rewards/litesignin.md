# LiteSignIn 签到

> LiteSignIn-1.9.0.0 | 每日签到奖励系统

LiteSignIn 是一秋小镇服务器的每日签到奖励插件。玩家每天登录服务器后可以进行签到，获取签到奖励。连续签到还可以获得额外的连续奖励，鼓励玩家每天回来游戏。

## 📋 功能概览

| 功能 | 说明 |
| :--- | :--- |
| 每日签到 | 玩家每天可签到一次，获取基础奖励 |
| 连续签到奖励 | 连续多天签到可获得递增的额外奖励 |
| 补签系统 | 支持使用补签卡补签错过的天数（如已配置） |
| 签到排行榜 | 查看全服签到连续天数排名 |
| 奖励自定义 | 管理员可自定义每天的签到奖励内容 |
| 多语言支持 | 支持中文等语言的签到提示信息 |

## 🎯 如何每天签到

签到操作非常简单，只需在游戏中执行以下命令即可：

```
/litesignin
```

或者使用简写命令：

```
/sign
```

[!TIP]
建议你每天登录服务器后第一时间进行签到，这样就不会忘记。你也可以将签到命令绑定到 zMenu 快捷菜单中，通过 GUI 一键签到。

### 签到流程

1. 登录一秋小镇服务器
2. 完成AuthMe登录验证
3. 在聊天框输入 `/litesignin` 或 `/sign`
4. 收到签到成功提示和奖励发放通知
5. 查看背包确认奖励物品

[!NOTE]
签到是基于服务器时间的，每天的签到窗口从服务器时间 00:00 开始重置。如果你在深夜 23:59 签到后，需要等到第二天 00:00 之后才能再次签到。

## 🎁 奖励系统

### 基础签到奖励

每次签到都会获得基础奖励，奖励内容可能包括：

| 奖励类型 | 说明 |
| :--- | :--- |
| 游戏币 | 通过 XConomy 发放一定数量的游戏币 |
| 经验值 | 获得一定量的经验值 |
| 特殊物品 | 随机或固定的特殊物品奖励 |
| 补签卡 | 获得补签卡道具（如已开启补签功能） |

### 连续签到奖励

连续签到天数越多，获得的奖励越丰厚。连续签到奖励采用阶梯递增模式：

| 连续天数 | 额外奖励 | 说明 |
| :--- | :--- | :--- |
| 第 1 ~ 6 天 | 基础奖励 | 每日标准签到奖励 |
| 第 7 天 | ★ 额外稀有物品 | 周奖励，包含稀有材料 |
| 第 14 天 | ★★ 更丰厚奖励 | 双周奖励，包含高级物品 |
| 第 21 天 | ★★★ 豪华奖励 | 三周奖励，包含珍贵道具 |
| 第 30 天 | ★★★★ 超级奖励 | 月度大奖，包含限定物品 |
| 第 60 天 | ★★★★★ 传说奖励 | 双月奖励，包含传说级道具 |
| 第 100 天 | 👑 百日纪念奖 | 特殊纪念奖励 |

[!TIP]
连续签到是累积计算的，只要每天签到不断即可。如果你某天忘记签到，连续天数会重置为 0。请尽量保持每天签到的习惯以获取最高等级的连续奖励。

### 补签系统

如果你不小心错过了某天的签到，可以使用补签卡进行补签（如服务器已开启此功能）。

| 命令 | 说明 |
| :--- | :--- |
| `/litesignin retro <日期>` | 补签指定日期 |
| `/litesignin retro` | 打开补签日历界面 |

[!WARNING]
补签卡是有限道具，通常通过连续签到奖励或活动获得。请谨慎使用补签卡，优先保持每天签到的习惯。

## 📜 命令一览

### 玩家命令

| 命令 | 说明 | 权限要求 |
| :--- | :--- | :--- |
| `/litesignin` | 执行每日签到 | 无 |
| `/sign` | 签到简写命令 | 无 |
| `/litesignin gui` | 打开签到日历 GUI | 无 |
| `/litesignin stats` | 查看个人签到统计 | 无 |
| `/litesignin top` | 查看全服签到排行榜 | 无 |
| `/litesignin retro` | 打开补签界面 | 无 |

### 管理员命令

| 命令 | 说明 | 权限要求 |
| :--- | :--- | :--- |
| `/litesignin reload` | 重新加载配置文件 | `litesignin.admin` |
| `/litesignin set <玩家> <天数>` | 设置玩家连续签到天数 | `litesignin.admin` |
| `/litesignin reset <玩家>` | 重置玩家签到记录 | `litesignin.admin` |
| `/litesignin give <玩家> <补签卡数量>` | 给予玩家补签卡 | `litesignin.admin` |
| `/litesignin force <玩家>` | 强制为某玩家执行签到 | `litesignin.admin` |

[!NOTE]
管理员可以使用 `/litesignin set` 命令来修正玩家的签到数据。在进行数据修正前请确认操作无误，错误的修改可能影响玩家的连续签到奖励获取。

## 📊 签到统计

你可以通过签到统计功能了解自己的签到情况：

- **总签到天数**：历史累计签到总天数
- **当前连续天数**：当前连续签到的天数
- **最长连续天数**：历史上最长的连续签到记录
- **本月签到天数**：当前自然月内的签到天数

[!TIP]
坚持每天签到不仅是为了获取奖励，更是一种参与社区的方式。快去签到吧！
