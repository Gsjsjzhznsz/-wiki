# LushRewards 在线奖励

> LushRewards-3.3.2 | 在线时间奖励系统

LushRewards 是一秋小镇服务器的在线时间奖励系统。它根据玩家在服务器中的在线时长发放奖励，玩家在线时间越长，获得的奖励越丰厚。系统通过里程碑和奖励阶梯机制，鼓励玩家积极参与游戏。

## 📋 功能概览

| 功能 | 说明 |
| :--- | :--- |
| 在线时间追踪 | 精确追踪每位玩家的累计在线时间 |
| 里程碑奖励 | 达到特定在线时间节点时自动发放奖励 |
| 奖励阶梯 | 多层级递进式奖励体系 |
| 自动发放 | 达到条件后自动发放，无需手动领取 |
| 提醒通知 | 接近里程碑时发送提醒消息 |
| 统计查询 | 玩家可随时查询自己的在线时长 |

## ⏱️ 在线时间奖励机制

LushRewards 采用里程碑 + 奖励阶梯的双重奖励机制。你的在线时间会被持续记录，每当达到预设的时间节点，系统会自动为你发放对应的奖励。

### 奖励阶梯

在线奖励按照阶梯式递增，在线时间越长，每阶段获得的奖励越丰厚：

| 阶梯 | 累计在线时间 | 奖励等级 | 奖励内容说明 |
| :--- | :--- | :--- | :--- |
| 1 | 1 小时 | 🟢 新手 | 基础游戏币奖励 |
| 2 | 5 小时 | 🟢 入门 | 游戏币 + 基础材料 |
| 3 | 10 小时 | 🔵 进阶 | 游戏币 + 进阶材料 |
| 4 | 25 小时 | 🔵 熟练 | 游戏币 + 稀有材料 |
| 5 | 50 小时 | 🟣 资深 | 大量游戏币 + 珍贵物品 |
| 6 | 100 小时 | 🟣 老兵 | 丰厚游戏币 + 限定物品 |
| 7 | 200 小时 | 🟡 元老 | 豪华奖励包 + 特殊称号 |
| 8 | 500 小时 | 🟡 传奇 | 传说级奖励 + 独家外观 |
| 9 | 1000 小时 | 🔴 千时 | 千时纪念大奖 + 永久特殊效果 |
| 10 | 2000 小时 | 🔴 万时 | 终极奖励 + 服务器荣誉 |

[!TIP]
在线奖励是自动发放的，达到对应时间节点后你会在游戏中收到奖励发放的提示消息。请注意查看聊天栏的通知，以免错过奖励信息。

## 🏆 里程碑系统

里程碑是在线奖励中的特殊节点，通常对应较大的时间跨度，奖励也更为丰厚。

### 主要里程碑

| 里程碑 | 时间要求 | 特殊奖励 | 额外效果 |
| :--- | :--- | :--- | :--- |
| 🥉 铜牌里程碑 | 50 小时 | 铜牌称号 + 奖励包 | 聊天前缀变化 |
| 🥈 银牌里程碑 | 200 小时 | 银牌称号 + 奖励包 | 特殊聊天颜色 |
| 🥇 金牌里程碑 | 500 小时 | 金牌称号 + 奖励包 | 独家粒子效果 |
| 💎 钻石里程碑 | 1000 小时 | 钻石称号 + 奖励包 | 专属装饰物品 |
| 👑 皇冠里程碑 | 2000 小时 | 皇冠称号 + 终极奖励 | 服务器名人堂 |

[!NOTE]
里程碑奖励不仅包含物品奖励，还可能包含特殊的聊天权限、称号和装饰效果。具体奖励内容可能根据服务器活动进行调整，请以游戏内实际发放为准。

## 📜 命令一览

### 玩家命令

| 命令 | 说明 | 权限要求 |
| :--- | :--- | :--- |
| `/lushrewards` | 打开在线奖励信息面板 | 无 |
| `/lushrewards stats` | 查看个人在线统计 | 无 |
| `/lushrewards milestones` | 查看里程碑进度 | 无 |
| `/lushrewards top` | 查看全服在线时间排行 | 无 |

### 管理员命令

| 命令 | 说明 | 权限要求 |
| :--- | :--- | :--- |
| `/lushrewards reload` | 重新加载配置 | `lushrewards.admin` |
| `/lushrewards set <玩家> <时间>` | 设置玩家在线时间 | `lushrewards.admin` |
| `/lushrewards give <玩家> <奖励ID>` | 手动发放指定奖励 | `lushrewards.admin` |
| `/lushrewards reset <玩家>` | 重置玩家在线时间 | `lushrewards.admin` |
| `/lushrewards check <玩家>` | 检查玩家的奖励领取状态 | `lushrewards.admin` |

## 📊 在线统计

通过 LushRewards 的统计功能，你可以查看以下信息：

| 统计项目 | 说明 |
| :--- | :--- |
| 累计在线时间 | 历史总在线时长 |
| 本次在线时间 | 当前登录会话的在线时长 |
| 当前阶梯 | 当前所处的奖励阶梯等级 |
| 下一奖励 | 距离下一个奖励还需的在线时间 |
| 全服排名 | 在全服玩家中的在线时间排名 |

[!WARNING]
LushRewards 的在线时间统计基于实际在线时长计算。挂机（长时间无操作）可能不会计入在线时间，具体规则由服务器配置决定。请积极参与游戏活动以获取在线奖励。

## 🔄 与其他系统的联动
