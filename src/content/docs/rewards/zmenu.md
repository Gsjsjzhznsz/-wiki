# zMenu 快捷菜单

> zMenu-1.1.1.4 | 自定义快捷菜单系统

zMenu 是一秋小镇服务器的自定义 GUI 菜单系统。它为玩家提供了一个可视化的快捷操作界面，将常用功能整合到一个或多个 GUI 菜单中，让玩家通过点击即可执行各种操作，无需记忆大量命令。

## 📋 功能概览

| 功能 | 说明 |
| :--- | :--- |
| 自定义 GUI 菜单 | 管理员可完全自定义菜单的布局和内容 |
| 多页面菜单 | 支持菜单分页，容纳更多功能入口 |
| 动态图标 | 菜单项可动态显示玩家信息（如余额、在线时间等） |
| 条件显示 | 根据玩家权限或状态显示/隐藏特定菜单项 |
| 点击执行命令 | 点击菜单项可执行预设命令 |
| 占位符支持 | 支持 PlaceholderAPI 变量在菜单项中显示 |

## 🖼️ 菜单概览

一秋小镇目前配置了以下快捷菜单：

| 菜单名称 | 说明 | 打开方式 |
| :--- | :--- | :--- |
| 主菜单 | 服务器功能总入口 | `/zmenu` 或 `/menu` |
| 商店菜单 | 快速打开各类商店 | 主菜单中点击 |
| 传送菜单 | 快速传送相关功能 | 主菜单中点击 |
| 个人信息 | 查看个人数据和统计 | 主菜单中点击 |

### 主菜单布局

主菜单是 zMenu 的核心入口，包含以下功能分区：

| 位置 | 功能 | 说明 |
| :--- | :--- | :--- |
| 中间区域 | 核心功能 | 签到、商店、传送等常用功能 |
| 上方区域 | 个人信息 | 显示玩家余额、在线时间等 |
| 下方区域 | 辅助功能 | 帮助、规则、社区链接等 |
| 边框区域 | 装饰 | 纯装饰性物品，提升视觉效果 |

[!TIP]
你可以在游戏中输入 `/zmenu` 或 `/menu` 快速打开主菜单。如果你经常使用某个子菜单，可以记住它在主菜单中的位置，快速点击进入。

## 📜 命令一览

### 玩家命令

| 命令 | 说明 | 权限要求 |
| :--- | :--- | :--- |
| `/zmenu` | 打开主菜单 | 无 |
| `/menu` | 打开主菜单（别名） | 无 |
| `/zmenu open <菜单名>` | 打开指定名称的菜单 | 无 |

### 管理员命令

| 命令 | 说明 | 权限要求 |
| :--- | :--- | :--- |
| `/zmenu reload` | 重新加载所有菜单配置 | `zmenu.admin` |
| `/zmenu open <菜单名> <玩家>` | 为指定玩家打开菜单 | `zmenu.admin` |
| `/zmenu list` | 列出所有已注册的菜单 | `zmenu.admin` |

## ⚙️ 菜单自定义（管理员）

zMenu 的菜单配置文件位于 `plugins/zMenu/` 目录下。每个菜单对应一个独立的配置文件。

### 配置文件结构

| 文件/目录 | 说明 |
| :--- | :--- |
| `menus/` | 菜单配置文件目录 |
| `menus/main.yml` | 主菜单配置 |
| `menus/shop.yml` | 商店菜单配置 |
| `config.yml` | zMenu 全局配置 |

### 菜单项配置要素

| 配置项 | 说明 | 示例 |
| :--- | :--- | :--- |
| `material` | 物品材质 | `DIAMOND_SWORD` |
| `name` | 显示名称 | `§a每日签到` |
| `lore` | 物品描述 | `§7点击进行每日签到` |
| `slot` | 放置位置 | `13`（中间位置） |
| `commands` | 点击执行的命令 | `['litesignin']` |
| `condition` | 显示条件 | `permission: some.perm` |

[!WARNING]
修改 zMenu 配置文件时，请确保 YAML 格式正确。缩进错误或格式问题可能导致菜单无法正常加载。修改完成后使用 `/zmenu reload` 重载配置，并在游戏中测试菜单是否正常显示。

## 🔄 与其他插件的集成

zMenu 在一秋小镇中与多个插件紧密集成，作为统一的 GUI 入口：

| 集成插件 | 集成方式 | 说明 |
| :--- | :--- | :--- |
| LiteSignIn | 命令调用 | 通过菜单点击执行签到 |
| UltimateShop | 命令调用 | 通过菜单打开商店 |
| HuskHomes GUI | 命令调用 | 通过菜单打开家园管理 |
| LushRewards | 命令调用 | 通过菜单查看在线奖励 |
| PlaceholderAPI | 变量替换 | 在菜单项上显示动态玩家信息 |
| XConomy | 变量替换 | 在菜单中显示玩家余额 |
