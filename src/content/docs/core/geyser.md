# 基岩版互通（Geyser）

一秋小镇通过部署 **Geyser-Spigot** 实现了 Java 版与基岩版（Bedrock Edition）之间的跨平台互通。无论你使用的是手机、平板、主机还是 Windows 10 版本的 Minecraft，都可以直接加入一秋小镇，与 Java 版玩家在同一个世界中共同游玩。

## Geyser 工作原理

Geyser 是一个协议翻译中间件，它运行在服务端，负责在 Java 版协议和基岩版协议之间进行实时的双向翻译：

```
基岩版客户端 ←→ Geyser（协议翻译） ←→ Java 版服务端（Folia）
```

当基岩版玩家连接服务器时，Geyser 会将基岩版的数据包格式转换为 Java 版格式发送给服务端，同时将服务端的响应数据包转换回基岩版格式返回给玩家。整个翻译过程对玩家完全透明。

## 支持平台

| 平台 | 支持状态 | 备注 |
|------|----------|------|
| Android | ✅ 完全支持 | 手机和平板均可正常连接 |
| iOS / iPadOS | ✅ 完全支持 | iPhone 和 iPad 均可正常连接 |
| Windows 10/11 | ✅ 完全支持 | Minecraft for Windows（基岩版） |
| Xbox | ✅ 完全支持 | 需要通过 Xbox Live 账号连接 |
| Nintendo Switch | ✅ 完全支持 | 需要订阅 Nintendo Switch Online |
| PlayStation 4/5 | ✅ 完全支持 | 需要订阅 PS Plus |

[!TIP]
> 基岩版玩家连接时需要在外部服务器设置中手动添加服务器地址。请查阅一秋小镇的「服务器信息」页面获取具体的连接地址和端口。

## 连接配置

| 参数 | 值 |
|------|----|
| 服务器地址 | 请参考服务器信息页面的基岩版地址 |
| 端口 | 默认基岩版端口（19132） |
| 协议 | UDP（基岩版使用 UDP 协议） |

[!WARNING]
> 基岩版使用 **UDP 协议**而非 TCP 协议。如果你的网络环境对 UDP 进行了限制（如部分公司/校园网络），可能导致无法连接。请确保你的网络允许 UDP 19132 端口的出入站通信。

## GeyserUpdater — 自动更新

一秋小镇部署了 **GeyserUpdater** 插件，用于自动检测 Geyser 的最新版本并在维护时段完成更新。Minecraft 每次版本更新都可能涉及协议变更，Geyser 需要同步更新以支持新版客户端。GeyserUpdater 确保我们的 Geyser 始终保持最新，避免因版本滞后导致的连接问题。

## 皮肤系统

一秋小镇配合 **SkinsRestorer** 插件处理基岩版玩家的皮肤显示：

- 基岩版玩家的皮肤会通过 SkinsRestorer 正确渲染给 Java 版玩家。
- Java 版玩家的皮肤也会通过 Geyser 正确传递给基岩版玩家。
- 如果皮肤加载失败，会显示为默认的 Steve/Alex 皮肤。

[!NOTE]
> 基岩版玩家如需自定义皮肤，建议使用正版 Minecraft 账号登录。离线账号的皮肤在跨平台显示时可能存在问题。

## 已知限制

| 限制项 | 详细说明 |
|--------|----------|
| 部分方块状态 | 极少数新版本特有方块的交互在基岩版上可能表现不完全一致 |
| 自定义物品 NBT | 部分复杂的 NBT 数据在跨平台传输时可能丢失 |
| 红石显示 | 基岩版的红石粒子效果与 Java 版存在视觉差异 |
| 手势/表情 | Java 版独有的一些交互动作在基岩版上无法使用 |
| 输入法兼容 | 基岩版客户端的聊天输入法体验因平台而异 |

[!TIP]
> 如果你在基岩版上遇到方块显示异常或交互问题，可以尝试重新进入该区块或重启客户端。大部分情况下这是由于基岩版客户端的缓存导致的临时问题。
