# 版本兼容（Via 系列）

一秋小镇服务器部署了完整的 **Via 系列插件链**，实现了从 Minecraft 1.7 到最新 1.21+ 版本的全面兼容。无论你使用的是哪个版本的 Java 版客户端，都可以直接连接一秋小镇，无需切换版本。

## 支持版本范围

| 最低支持版本 | 最高支持版本 | 覆盖范围 |
|--------------|--------------|----------|
| 1.7.2 | 最新正式版（持续跟进） | 1.7.x ~ 1.21.x+ |

## Via 系列插件功能说明

### 各插件职责一览

| 插件名称 | 功能定位 | 处理的版本范围 | 说明 |
|----------|----------|----------------|------|
| **ViaVersion** | 前向兼容 | 当前服务端版本 → 更高版本客户端 | 允许新版本客户端连接旧版本服务端 |
| **ViaBackwards** | 后向兼容 | 当前服务端版本 → 较低版本客户端 | 允许旧版本客户端连接新版本服务端 |
| **ViaRewind** | 遗留版本支持 | 1.7.x ~ 1.12.x | 专门处理远古版本协议的翻译与转换 |
| **AutoViaUpdater** | 自动更新 | 全版本 | 自动检测并更新 Via 系列插件到最新兼容版本 |
| **ViaVersionStatus** | 版本检测 | 全版本 | 玩家连接时显示其真实客户端版本，方便排查兼容问题 |

### ViaVersion — 前向兼容

ViaVersion 是整个版本兼容链的核心。它通过在网络层拦截和转换客户端/服务端之间的数据包协议，让使用新版本客户端的玩家能够无缝连接到旧版本的服务端。例如，使用 1.21 客户端的玩家可以正常加入一秋小镇。

### ViaBackwards — 后向兼容

ViaBackwards 补充了 ViaVersion 的反方向兼容。当服务端运行在较新版本时，ViaBackwards 负责将服务端的新协议翻译为旧版本客户端能够理解的格式，使 1.13~1.20 等版本的客户端也能正常连接。

### ViaRewind — 遗留版本支持

Minecraft 1.7 到 1.12 期间的协议变化非常剧烈（如 1.13 的扁平化更新彻底重构了数据包格式），因此需要 ViaRewind 单独处理这些遗留版本的协议翻译。

[!NOTE]
> 由于 1.7.x 和 1.8.x 版本极为古老，部分新版本的内容（如新方块、新生物、新物品）在旧版客户端上**无法完美显示**，这是协议层面的客观限制，并非服务器 Bug。

### AutoViaUpdater — 自动更新

AutoViaUpdater 会定期检查 Via 系列插件的最新版本，并在服务器维护时段自动完成更新。这确保了一秋小镇的版本兼容链始终保持最新，能够第一时间支持 Minecraft 的新版本发布。

### ViaVersionStatus — 版本状态检测

当玩家加入服务器时，ViaVersionStatus 会在后台记录该玩家使用的实际客户端版本。管理员可以通过指令或日志查看这些信息，用于排查因版本差异导致的问题。

## 已知限制

| 限制项 | 说明 |
|--------|------|
| 新内容显示 | 旧版本客户端无法渲染新版本新增的方块、物品和生物 |
| 部分动画缺失 | 旧版本客户端可能缺少新版特有的动画效果 |
| ViaAprilFools | 愚人节特殊版本的协议支持为实验性功能，可能存在不稳定 |
| 极端旧版本 | 1.7.2 之前的版本不在支持范围内 |

[!TIP]
> 推荐使用 **1.20.x 或更高版本**的客户端连接一秋小镇，以获得最完整的游戏体验。虽然我们支持 1.7 以上的所有版本，但越新的客户端能显示的内容越丰富、体验越流畅。

[!WARNING]
> 如果你使用的是 Mod 客户端，请确保你的 Mod 与你选择的 Minecraft 版本匹配。Via 系列仅处理原版协议的转换，不保证所有 Mod 在跨版本连接时的兼容性。
