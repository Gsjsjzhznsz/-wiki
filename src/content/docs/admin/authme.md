# AuthMe 账户安全

> **插件版本**：AuthMe-5.7.0-FORK-Universal
> **适用服务端**：一秋小镇主服务器

AuthMe 是一秋小镇服务器的账户安全登录系统。由于一秋小镇为**离线模式（cracked/offline）**服务器，玩家无需正版验证即可进入，因此需要 AuthMe 来通过密码验证确保账户安全，防止他人冒用玩家身份。

## 为什么需要 AuthMe？

Minecraft 服务器分为两种验证模式：

| 模式 | 说明 | 是否需要 AuthMe |
|------|------|----------------|
| **在线模式（online）** | 通过 Mojang/微软服务器验证玩家身份 | 不需要（官方验证） |
| **离线模式（offline/cracked）** | 服务器自行验证，不连接官方服务器 | **需要**（防止冒用） |

[!WARNING]
> 在离线模式下，任何人都可以使用任意玩家名进入服务器。如果没有 AuthMe，恶意玩家可以输入你的用户名登录，访问你的背包、home 点和物品。AuthMe 通过密码登录机制彻底杜绝这一问题。

## 核心功能

| 功能 | 说明 |
|------|------|
| 密码注册与登录 | 玩家首次进入需注册密码，之后每次登录需验证 |
| 密码加密存储 | 支持多种加密算法，密码不以明文存储 |
| 登录会话管理 | 重新登录同一 IP 时可自动免密 |
| IP 限制 | 可限制账户绑定 IP 或 IP 段 |
| 反暴力破解 | 多次登录失败后自动临时封禁 |
| 未登录保护 | 未登录的玩家无法移动、交互或使用命令 |
| 安全退出 | 退出时自动清除会话，防止会话劫持 |

## 玩家命令

### 注册与登录

| 命令 | 说明 | 示例 |
|------|------|------|
| `/register <密码> <确认密码>` | 首次进入服务器时注册账户 | `/register mypass123 mypass123` |
| `/login <密码>` | 每次进入服务器后登录 | `/login mypass123` |
| `/changepassword <旧密码> <新密码>` | 修改账户密码 | `/changepassword old123 new456` |
| `/logout` | 主动退出登录（切换账户时使用） | `/logout` |
| `/unregister <密码>` | 注销当前账户 | `/unregister mypass123` |

[!TIP]
> **密码安全建议**：请使用包含字母和数字的强密码，长度至少 6 位。不要使用与用户名相同的密码，也不要在多个服务器上使用相同密码。

### 登录流程

```
玩家加入服务器
    │
    ▼
检测是否已注册？ ──否──▶ 显示注册提示 ──▶ /register 密码 确认 ──▶ 进入游戏
    │是
    ▼
检测是否已登录？ ──是──▶ 进入游戏
    │否
    ▼
显示登录提示 ──▶ /login 密码 ──▶ 验证通过 ──▶ 进入游戏
    │                        │
    │                     验证失败
    │                        ▼
    │                   提示重新输入（最多 N 次）
    │                        │
    │                     超过次数
    │                        ▼
    │                   临时踢出
```

## 安全功能详解

### 密码加密

AuthMe FORK 5.7.0 版本支持以下加密算法：

| 加密算法 | 安全等级 | 说明 |
|----------|----------|------|
| **SHA256** | 中 | 一秋小镇默认使用，配合盐值（salt）增强安全性 |
| BCrypt | 高 | 自适应哈希算法，抗暴力破解能力强 |
| Argon2 | 很高 | 密码哈希竞赛冠军算法，需额外依赖 |
| PBKDF2 | 高 | 基于密钥的派生函数，广泛使用 |
| SHA512 | 中 | SHA256 的加强版本 |

[!NOTE]
> 一秋小镇当前使用 **SHA256 + 盐值**加密方案。密码在数据库中不以明文存储，即使数据库泄露攻击者也无法直接还原密码。

### 会话管理

| 会话功能 | 说明 |
|----------|------|
| 自动登录 | 同一 IP 地址在会话有效期内重新登录时自动通过验证 |
| 会话超时 | 登录后会话持续一定时间，超时后需要重新登录 |
| 手动登出 | 使用 `/logout` 命令可立即清除会话 |
| 服务器重启 | 重启后所有会话自动失效，需要重新登录 |

### IP 限制

| 限制类型 | 说明 |
|----------|------|
| 单 IP 绑定 | 账户只能从注册时的 IP 登录 |
| IP 段限制 | 允许同一网段的 IP 登录（适用于动态 IP 用户） |
| 动态 IP 模式 | 不绑定 IP，仅依靠密码验证 |

[!WARNING]
> 一秋小镇目前使用**动态 IP 模式**，不强制绑定 IP。这是因为许多玩家的 IP 地址会频繁变化。如果你使用了固定 IP，建议联系管理员为你的账户开启 IP 绑定以增强安全性。

### 反暴力破解

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `maxLoginTries` | 5 | 最大登录尝试次数 |
| `maxJoinPerIp` | 2 | 同一 IP 同时在线的最大账户数 |
| `tempbanMaxLoginTries` | true | 超过尝试次数后是否临时封禁 |
| `tempbanLength` | 10m | 临时封禁时长 |

[!TIP]
> 如果你在输入密码时连续输错 5 次，你的 IP 将被临时封禁 10 分钟。这是正常的安全保护机制。如果确实忘记了密码，请联系管理员通过后台重置。

## 未登录状态下的限制

玩家未完成登录时，以下行为将被禁止：

| 行为 | 是否允许 |
|------|----------|
| 移动/行走 | ❌ 禁止 |
| 与方块交互（开门、使用工作台等） | ❌ 禁止 |
| 攻击其他玩家/生物 | ❌ 禁止 |
| 捡起物品 | ❌ 禁止 |
| 丢弃物品 | ❌ 禁止 |
| 聊天发送消息 | ❌ 禁止（仅可私聊管理员） |
| 使用命令（除 /login /register） | ❌ 禁止 |
| 受到伤害/死亡 | ❌ 禁止（无敌状态） |
| 查看服务器信息 | ✅ 允许 |

[!NOTE]
> 未登录的玩家处于完全无操作状态，既无法与世界互动也不会受到伤害。这是为了保护已注册玩家的账户不被未验证的人操作。

## 管理员命令

| 命令 | 说明 | 权限 |
|------|------|------|
| `/authme reload` | 重新加载 AuthMe 配置 | `authme.admin.reload` |
| `/authme register <玩家> <密码>` | 管理员为玩家注册账户 | `authme.admin.register` |
| `/authme changepassword <玩家> <新密码>` | 管理员重置玩家密码 | `authme.admin.changepassword` |
| `/authme unregister <玩家>` | 管理员注销玩家账户 | `authme.admin.unregister` |
| `/authme forceLogin <玩家>` | 强制玩家通过登录验证 | `authme.admin.forcelogin` |
| `/authme getip <玩家>` | 查看玩家注册/最后登录的 IP | `authme.admin.getip` |
| `/authme lastlogin <玩家>` | 查看玩家最后登录时间 | `authme.admin.lastlogin` |
| `/authme accounts <玩家>` | 查看同一 IP 下的所有账户 | `authme.admin.accounts` |
| `/authme purgebanned` | 清除被封禁玩家的 AuthMe 数据 | `authme.admin.purge` |
| `/authme converter <类型>` | 数据库格式转换工具 | `authme.admin.converter` |

[!TIP]
> 管理员可以使用 `/authme changepassword` 命令直接为忘记密码的玩家重置密码，无需操作数据库。这是处理玩家密码问题最安全的方式。

## FORK 版本特性

一秋小镇使用的是 **AuthMe 5.7.0 FORK** 版本，而非原版 AuthMe Reloaded。FORK 版本包含以下额外改进：

| 特性 | 说明 |
|------|------|
| 更好的兼容性 | 修复了原版在较新服务端版本上的兼容性问题 |
| 性能优化 | 减少了登录验证时的数据库查询开销 |
| 额外加密支持 | 增加了对更多现代加密算法的支持 |
| Bug 修复 | 修复了原版中多个已知的会话管理问题 |
| MySQL 优化 | 改进了连接池管理和异步查询性能 |

## 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 注册后每次登录都要输密码 | 正常行为 | 这是安全机制，确保每次都是本人操作 |
| 换了 IP 后无法自动登录 | 会话绑定 IP | 重新输入密码即可，或联系管理员 |
| 提示"你已经注册了" | 用户名已被注册 | 联系管理员核实是否为本人注册 |
| 密码输对但仍登录失败 | 密码包含特殊字符 | 联系管理员重置密码，避免使用特殊字符 |
| 登录后瞬移回出生点 | 插件配置的登录位置 | 属于正常行为 |
| 连续输错被临时封禁 | 触发反暴力破解机制 | 等待 10 分钟或联系管理员解封 |

[!WARNING]
> **切勿将你的密码告诉任何人**，包括自称管理员的人。一秋小镇的管理员永远不会向你索要密码。如果有人声称是管理员并索要你的密码，请立即截图举报。
