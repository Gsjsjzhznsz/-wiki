# Orebfuscator 矿石混淆反X射线

**插件文件：** `orebfuscator-plugin-5.6.1.jar`
**分类：** 管理/安全

Orebfuscator 是一款强大的服务器端反作弊插件，专门用于对抗玩家使用 X-Ray（透视）模组或资源包来非法获取矿石位置的行为。本服已部署该插件以维护公平的游戏环境。

## 工作原理

Orebfuscator 通过在网络层面拦截并修改发送给客户端的区块数据来工作。当服务器向客户端发送区块信息时，插件会将特定的方块（如钻石矿、绿宝石矿、远古残骸等）临时替换为普通石头或其他伪装方块。只有当玩家真正挖掘到附近或满足特定条件时，这些方块才会恢复为原始状态。这意味着即使玩家使用 X-Ray 模组，也无法看到被隐藏的矿石。

## 被混淆的方块

| 方块类型 | 伪装为 | 说明 |
|---------|--------|------|
| 钻石矿 | 石头 | 最常见的透视目标 |
| 绿宝石矿 | 石头 | 稀有矿石保护 |
| 远古残骸 | 下界岩 | 下界资源保护 |
| 基岩 | 石头 | 防止利用基岩定位 |
| 刷怪笼 | 普通 | 防止刷怪塔探测 |
| 箱子（地下） | 石头 | 防止掠夺箱子的透视 |
| 末地箱 | 石头 | 防止定位其他玩家末地箱 |

> [!WARNING]
> 由于矿石混淆机制，玩家在地下采矿时可能会注意到矿石「突然出现」的现象——这是正常行为，说明你正在接近隐藏的矿石。请勿报告为 Bug。

## 性能影响

Orebfuscator 会对服务器性能产生一定影响，因为它需要实时处理和修改网络数据包。本服已针对性能进行了以下优化：

- **异步处理：** 方块混淆在独立线程中完成，减少对主线程的影响
- **缓存机制：** 已处理的区块数据会被缓存，避免重复计算
- **距离优化：** 仅对玩家周围一定范围内的区块启用混淆

> [!TIP]
> 如果你在采矿时感觉到偶尔的卡顿，可能与 Orebfuscator 的数据处理有关。通常情况下这种影响极小，不会影响正常游戏体验。

## 常见问题

**Q: 为什么我挖石头时突然挖到了钻石？**
A: 这是 Orebfuscator 的正常工作机制。矿石在你接近时才会显示为原始形态，所以「突然出现」是预期行为。

**Q: Orebfuscator 会影响红石电路吗？**
A: 不会。插件仅对特定矿石和特殊方块进行混淆，红石组件不受影响。

**Q: 使用原版资源包会受到影响吗？**
A: 不会。Orebfuscator 作用于服务端数据层面，与客户端资源包无关。
