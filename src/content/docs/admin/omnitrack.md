# OmniTrack 全能行为追踪系统

**插件文件：** `OmniTrack-1.0-beta.jar`
**分类：** 管理/监控

OmniTrack 是一款功能全面的服务器端玩家行为追踪插件，能够实时监控和记录玩家在服务器中的各种操作与行为。本服使用该插件作为核心监控工具之一，帮助管理团队维护服务器秩序、处理纠纷和排查异常行为。

## 追踪功能概览

OmniTrack 覆盖了玩家在服务器中几乎所有的关键行为，以下是主要追踪模块：

| 追踪模块 | 记录内容 | 数据保留时间 |
---------|---------|------------|
| 方块操作 | 方块的放置与破坏 | 30天 |
| 物品交互 | 箱子、漏斗、熔炉等容器操作 | 30天 |
| 实体交互 | 动物伤害/击杀、村民交易 | 14天 |
| 聊天记录 | 公共聊天、私聊消息 | 60天 |
| 命令记录 | 玩家执行的所有命令 | 30天 |
| 登录日志 | 上线/下线时间、IP地址 | 90天 |
| 传送记录 | TPA、home、warp 等传送事件 | 14天 |
| 交易记录 | 玩家间物品与货币交易 | 30天 |

## 管理员查询命令

管理团队成员可以使用以下命令查询玩家行为记录：

```
/omnitrack lookup <玩家名>           查看玩家综合记录
/omnitrack block <玩家名> <坐标>     查询指定位置的方块操作
/omnitrack container <玩家名>        查看容器交互记录
/omnitrack chat <玩家名> [关键词]    搜索聊天记录
/omnitrack command <玩家名> [命令]   搜索命令记录
/omnitrack login <玩家名>            查看登录历史
/omnitrack rollback <玩家名>         回滚玩家的方块操作
```

> [!WARNING]
- OmniTrack 记录的聊天日志仅用于安全审计和纠纷处理，管理团队承诺不会无故查看玩家私人对话
- 如需查询自己的记录，可以联系在线管理员申请数据调取
- 所有查询操作本身也会被记录，确保管理透明

## 数据安全与隐私

本服对 OmniTrack 采集的数据实行严格的访问控制：

- **分级权限：** 仅管理员及以上等级可访问完整数据，版主仅可查看与自己处理案件相关的记录
- **日志审计：** 每一次数据查询都会被记录，定期审查是否有异常查询行为
- **自动清理：** 超过保留期的数据会自动删除，不会永久存储
- **数据加密：** 存储在数据库中的敏感数据（如 IP 地址）经过加密处理

> [!TIP]
如果发现物品丢失、建筑被破坏或遭遇任何不公平行为，请及时联系在线管理员。OmniTrack 的详细日志能够帮助我们快速定位问题并恢复损失。

## 应用场景

- **盗号调查：** 通过登录 IP 变化和异常行为判断账号是否被盗用
- ** grief 处理：** 精确回滚恶意破坏的方块操作
- **纠纷调解：** 通过交易记录和聊天记录还原事件真相
- **作弊检测：** 辅助识别异常行为模式（配合其他反作弊插件使用）

## 常见问题

**Q: 普通玩家可以查看自己的行为记录吗？**
A: 目前普通玩家无法直接查询，但可以联系管理员申请查看个人记录。

**Q: 数据能保留多久？**
A: 根据数据类型不同，保留 14 至 90 天不等，详见上方表格。
