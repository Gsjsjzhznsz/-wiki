# Worlds 多世界

> worlds-4.3.0-pre1 | 多世界管理系统

Worlds 是一秋小镇服务器的多世界管理插件。它允许服务器拥有多个独立的世界，每个世界可以有不同的地形生成规则、游戏规则和环境设置。玩家可以在不同世界之间自由移动，体验不同类型的游戏内容。

## 📋 功能概览

| 功能 | 说明 |
| :--- | :--- |
| 多世界创建 | 支持创建多个独立世界 |
| 世界类型管理 | 支持多种世界生成类型 |
| 世界间传送 | 玩家可在不同世界之间快速移动 |
| 独立游戏规则 | 每个世界可设置不同的游戏规则 |
| 世界边界 | 可为每个世界设置独立的边界 |
| 世界加载控制 | 控制世界的加载/卸载状态 |
| 世界种子设置 | 每个世界可使用不同的种子 |

## 🌍 世界类型

Minecraft 支持多种世界生成类型，Worlds 插件在此基础上提供了便捷的管理接口。

### 常用世界类型

| 世界类型 | 说明 | 适用场景 |
| :--- | :--- | :--- |
| `NORMAL` | 标准世界生成 | 主世界、生存区域 |
| `FLAT` | 超平坦世界 | 建筑测试、特殊活动 |
| `NETHER` | 下界环境 | 下界资源采集 |
| `THE_END` | 末地环境 | 末地探险 |
| `VOID` | 虚空世界 | 创造建筑、展示区域 |
| `AMPLIFIED` | 放大化地形 | 特殊地形体验 |
| `LARGE_BIOMES` | 大型生物群系 | 更广阔的生态体验 |

### 一秋小镇世界列表

| 世界名称 | 世界类型 | 说明 | 建筑规则 |
| :--- | :--- | :--- | :--- |
| `world` | NORMAL | 主世界，生存游戏区域 | 允许建筑（需领地） |
| `world_nether` | NETHER | 下界，资源采集区域 | 禁止建筑 |
| `world_the_end` | THE_END | 末地，探险与战斗区域 | 禁止建筑 |
| `creative` | FLAT | 创造世界，自由建造区域 | 允许自由建筑 |
| `resource` | NORMAL | 资源世界，定期重置 | 禁止建筑 |

[!TIP]
资源世界（resource）会定期重置，请不要在资源世界中建立永久性建筑或存放重要物品。主世界（world）才是你的永久家园。

## 🚀 如何在世界之间移动

### 方法一：使用命令

| 命令 | 说明 | 权限要求 |
| :--- | :--- | :--- |
| `/worlds tp <世界名>` | 传送到指定世界 | 无 |
| `/worlds list` | 列出所有可用世界 | 无 |
| `/worlds info <世界名>` | 查看世界详细信息 | 无 |

### 方法二：使用传送门

| 传送门类型 | 连接世界 | 说明 |
| :--- | :--- | :--- |
| 下界传送门 | 主世界 ↔ 下界 | 原版下界传送门机制 |
| 末地传送门 | 主世界 → 末地 | 需要末地传送门框架 |
| 自定义传送门 | 自定义 | 服务器可能配置了自定义传送门 |

### 方法三：使用 HuskHomes

你可以使用 HuskHomes 系统在不同世界中设置家和传送点：

| 命令 | 说明 |
| :--- | :--- |
| `/sethome <名称>` | 在当前位置设置家 |
| `/home <名称>` | 传送到已设置的家 |
| `/warp <名称>` | 传送到公共传送点 |

[!NOTE]
使用传送命令在世界间移动时，可能会有短暂的加载延迟，特别是在首次进入某个世界时。这是正常现象，系统正在为你加载该世界的区块数据。

## ⚙️ 管理员命令

| 命令 | 说明 | 权限要求 |
| :--- | :--- | :--- |
| `/worlds create <名称> [类型]` | 创建新世界 | `worlds.admin` |
| `/worlds delete <名称>` | 删除世界 | `worlds.admin` |
| `/worlds load <名称>` | 加载世界 | `worlds.admin` |
| `/worlds unload <名称>` | 卸载世界 | `worlds.admin` |
| `/worlds teleport <玩家> <世界名>` | 将玩家传送到指定世界 | `worlds.admin.teleport` |
| `/worlds setspawn <世界名>` | 设置世界出生点 | `worlds.admin` |
| `/worlds gamerule <世界名> <规则> <值>` | 设置世界游戏规则 | `worlds.admin` |
| `/worlds border <世界名> <大小>` | 设置世界边界 | `worlds.admin` |
| `/worlds reload` | 重新加载配置 | `worlds.admin` |

## 📊 世界规则对比

| 游戏规则 | 主世界 | 下界 | 末地 | 创造世界 | 资源世界 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| PVP | ❌ 禁用 | ❌ 禁用 | ✅ 允许 | ❌ 禁用 | ❌ 禁用 |
| 建筑破坏 | ⚠️ 需领地 | ❌ 禁止 | ❌ 禁止 | ✅ 自由 | ❌ 禁止 |
| 生物生成 | ✅ 正常 | ✅ 正常 | ✅ 正常 | ❌ 禁止 | ✅ 正常 |
| 生物破坏 | ✅ 正常 | ✅ 正常 | ✅ 正常 | ❌ 禁止 | ✅ 正常 |
| 定期重置 | ❌ 否 | ❌ 否 | ❌ 否 | ❌ 否 | ✅ 是 |

[!WARNING]
不同世界有不同的规则，请在进入新世界前了解该世界的规则。特别是在末地世界中 PVP 是开启的，请注意安全。资源世界会定期重置，请及时将重要物品带回主世界。

| HuskHomes | 家园和传送点支持跨世界 |
| SeeMore | 每个世界的视距独立优化 |
| Chunky | 可对新创建的世界进行预生成 |
| squaremap | 每个世界有独立的地图渲染 |
| LuckPerms | 可设置世界特定的权限 |
| LushRewards | 在线时间统计跨世界计算 |
