# MiniMOTD 服务器图标

> minimotd-paper-2.2.4 | 服务器列表 MOTD 与图标管理

MiniMOTD 是一秋小镇服务器使用的服务器列表 MOTD（Message of the Day）与服务器图标管理插件。它允许管理员自定义玩家在服务器选择界面中看到的 MOTD 消息、服务器图标和玩家数量显示格式，让服务器在多人游戏服务器列表中展示出专业和美观的外观。

## 📋 功能概览

| 功能 | 说明 |
| :--- | :--- |
| 自定义 MOTD | 支持多行 MOTD 消息，可使用颜色代码和样式 |
| 服务器图标 | 支持设置服务器在列表中显示的图标 |
| 玩家数量显示 | 自定义在线/最大玩家数的显示格式 |
| 多 MOTD 轮换 | 支持多条 MOTD 消息随机或顺序轮换 |
| 动态变量 | 支持 PlaceholderAPI 变量在 MOTD 中使用 |
| 版本显示 | 自定义服务器列表中显示的版本信息 |

## 🎨 自定义 MOTD

MOTD（Message of the Day）是玩家在 Minecraft 服务器列表中看到的描述文字。MiniMOTD 允许管理员设置美观且信息丰富的 MOTD。

### MOTD 显示位置

在 Minecraft 的服务器列表界面中，MOTD 显示在服务器名称下方、玩家数量上方。它是玩家对服务器的第一印象。

### MOTD 格式

MiniMOTD 支持以下 MOTD 格式化选项：

| 格式选项 | 说明 | 示例 |
| :--- | :--- | :--- |
| 颜色代码 | 使用 § 或 & 符号加颜色代码 | `&a&l一秋小镇`
| 换行 | 使用 `\n` 进行换行 | `第一行\n第二行` |
| 样式代码 | 粗体、斜体、下划线等 | `&b&n带下划线`
| 十六进制颜色 | 使用 `#` 号加十六进制颜色值 | `&#FF5555红色` |

### MOTD 轮换

MiniMOTD 支持配置多条 MOTD 消息进行轮换显示：

| 模式 | 说明 |
| :--- | :--- |
| 随机轮换 | 每次服务器列表刷新时随机选择一条 MOTD |
| 顺序轮换 | 按照配置顺序依次显示 MOTD |
| 固定显示 | 始终显示同一条 MOTD |

[!TIP]
MOTD 消息会在每次服务器列表刷新时更新。在服务器列表中右键点击服务器条目可以手动刷新，MOTD 会随之更新为轮换中的下一条消息。

## 🖼️ 服务器列表图标

服务器图标是显示在服务器列表中服务器名称左侧的 64×64 像素图片。

### 图标规范

| 属性 | 要求 |
| :--- | :--- |
| 尺寸 | 64 × 64 像素 |
| 格式 | PNG |
| 大小 | 不超过 64 KB |
| 背景色 | 推荐使用 Minecraft 风格的棕色背景 |

### 图标配置

| 配置项 | 说明 |
| :--- | :--- |
| 图标文件路径 | 服务器图标的 PNG 文件位置 |
| 多图标轮换 | 支持设置多个图标进行轮换 |
| 图标形状 | 原版为方形，可通过特殊处理显示为圆形 |

[!NOTE]
MiniMOTD 使用的服务器图标与 Minecraft 服务端 `server-icon.png` 是独立的。MiniMOTD 的图标优先级更高，会覆盖服务端的默认图标。如需使用服务端默认图标，请禁用 MiniMOTD 的图标功能。

## 👥 玩家数量显示

MiniMOTD 可以自定义玩家数量的显示格式，让服务器列表中的玩家信息展示更加直观。

### 显示选项

| 选项 | 说明 | 示例 |
| :--- | :--- | :--- |
| 当前在线 | 显示当前在线玩家数 | `12`
| 最大人数 | 显示最大玩家数 | `100`
| 自定义文本 | 自定义前后缀 | `📜 12 / 100 人` |
| 隐藏人数 | 隐藏真实玩家数量 | `*** / ***` |

### 一秋小镇的显示格式

```
在线: {online} / {max}
```

实际显示效果：`在线: 12 / 100`

## ⚙️ 配置说明

MiniMOTD 的配置文件位于 `plugins/minimotd/config.yml`。

### 主要配置项

| 配置项 | 说明 | 示例 |
| :--- | :--- | :--- |
| `motd` | MOTD 消息列表 | 见下方示例 |
| `icon` | 服务器图标配置 | 图标文件路径 |
| `player-count` | 玩家数量显示配置 | 显示格式 |
| `version` | 版本显示配置 | 自定义版本文字 |

### MOTD 配置示例

```yaml
motd:
  - line-1: "&6&l一秋小镇 &7| &fMinecraft 生存服务器"
    line-2: "&a欢迎加入！&7 在线: &e{online}&7/&e{max}"
```

[!WARNING]
MOTD 中的中文在部分旧版客户端上可能显示为方块。MiniMOTD 使用 MiniMessage 格式系统，确保你的格式代码与插件版本兼容。修改配置后需要重启服务器或使用重载命令才能生效。
