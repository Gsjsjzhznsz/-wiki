# 蓝梦抽奖系统 BlueDream Lottery

**插件文件：** `BlueDream_Lottery-1.2.2.jar`
**分类：** 杂项/娱乐

蓝梦抽奖系统（BlueDream Lottery）是一款为 Minecraft 服务器设计的趣味抽奖插件，为玩家提供多种抽奖方式，让每位玩家都有机会获得丰厚奖励。在本服中，玩家可以通过游戏内积累的货币或特殊道具参与抽奖，增添游戏的乐趣和期待感。

## 抽奖方式

本服配置了以下几种抽奖模式，每种模式有不同的参与条件和奖励池：

| 抽奖类型 | 参与方式 | 奖励等级 | 每日次数限制 |
---------|---------|---------|------------|
| 新手抽奖 | 免费每日一次 | 普通 | 1次 |
| 金币抽奖 | 消耗游戏币 | 普通/稀有/史诗 | 无限制 |
| 积分抽奖 | 消耗在线时长积分 | 稀有/史诗/传说 | 无限制 |
| 限定抽奖 | 消费限定代币 | 传说/限定 | 活动期间 |

## 奖励等级说明

- **普通（白）：** 常见物品，如基础材料、食物、少量经验瓶等
- **稀有（蓝）：** 中等价值物品，如附魔书、特殊工具、宠物蛋等
- **史诗（紫）：** 高价值物品，如稀有坐骑、特殊称号、定制道具等
- **传说（金）：** 极稀有物品，如限定皮肤、特殊效果武器、永久增益等
- **限定（红）：** 仅在特定活动中可获得的独占奖励

> [!NOTE]
> 抽奖结果完全随机，保底机制会在连续未获得高等级奖励时逐渐提升稀有物品的概率。具体保底次数请参阅游戏内帮助信息。

## 使用方法

1. 在主城或 spawn 区域找到**抽奖 NPC**
2. 右键点击 NPC 打开抽奖界面
3. 选择你想参与的抽奖类型
4. 点击「抽奖」按钮进行抽取
5. 奖励将自动存入你的背包或邮箱

也可使用命令直接打开抽奖界面：

```
/lottery          打开抽奖主菜单
/lottery daily    免费每日抽奖
/lottery points   使用积分抽奖
```

> [!TIP]
- 每日免费抽奖记得每天领取，积少成多
- 积分可以通过在线挂机、完成任务、参与活动等方式获取
- 限定抽奖活动会提前在群内公告，请留意通知
- 抽到的重复物品会自动转化为等值补偿

## 常见问题

**Q: 抽奖获得的物品可以交易吗？**
A: 大部分抽奖物品允许玩家间自由交易，但标注「绑定」的限定物品不可交易。

**Q: 抽奖记录在哪里查看？**
A: 使用 `/lottery history` 命令可以查看你近期的抽奖记录。
