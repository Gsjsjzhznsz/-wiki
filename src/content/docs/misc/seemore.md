# SeeMore 视距优化

> SeeMore-1.0.2 | 视距渲染优化插件

SeeMore 是一秋小镇服务器使用的视距渲染优化插件。它通过智能的区块加载和渲染策略，在保证玩家视觉体验的同时，有效降低服务器的性能开销。这让玩家可以在较远的距离看到更多内容，同时不会对服务器 TPS 造成显著影响。

## 📋 功能概览

| 功能 | 说明 |
| :--- | :--- |
| 动态视距调整 | 根据服务器性能动态调整玩家可看到的区块数量 |
| 高效区块加载 | 优化区块加载策略，减少卡顿 |
| 延迟加载 | 非关键区块延迟加载，优先保证近处渲染 |
| 渐进式渲染 | 由近到远逐步加载区块，避免瞬间卡顿 |
| 性能监控 | 实时监控渲染性能，自动调节视距 |
| 兼容性优化 | 与其他渲染相关插件良好兼容 |

## 🔍 工作原理

### 传统视距的问题

在 Minecraft 原版机制中，服务器的视距（View Distance）是一个全局设置。所有玩家共享相同的视距值，这意味着：

- 视距设置过高 → 服务器需要为每个玩家加载大量区块，导致 TPS 下降
- 视距设置过低 → 玩家视野受限，体验不佳
- 无法根据实时负载动态调整 → 高峰期可能出现性能问题

### SeeMore 的优化方案

SeeMore 通过以下方式解决上述问题：

| 优化策略 | 说明 | 性能影响 |
| :--- | :--- | :--- |
| 动态视距 | 根据当前 TPS 自动增减每玩家的视距 | ⬇️ 显著降低负载 |
| 智能预加载 | 在玩家移动方向预加载区块 | ⬆️ 减少移动时卡顿 |
| 按需渲染 | 仅渲染玩家视野范围内的区块 | ⬇️ 减少无效计算 |
| 异步加载 | 区块加载在异步线程中执行 | ⬇️ 减少主线程阻塞 |
| 缓存机制 | 缓存已加载区块数据 | ⬆️ 重复访问更快 |

[!TIP]
SeeMore 的优化对玩家来说是完全透明的。你不需要做任何额外的设置或操作，系统会在后台自动工作。你可能会注意到在服务器负载较高时，远处的方块会稍慢加载，这是正常的动态调节行为。

## ⚡ 性能优势

### 对服务器的影响

| 指标 | 无 SeeMore | 有 SeeMore | 改善程度 |
| :--- | :--- | :--- | :--- |
| TPS 稳定性 | 容易波动 | 更加稳定 | ⬆️ 显著提升 |
| 内存使用 | 较高 | 优化后降低 | ⬇️ 降低 15-30% |
| 区块加载速度 | 一般 | 更快更流畅 | ⬆️ 提升 |
| 玩家数承载力 | 较低 | 更高 | ⬆️ 提升 20-40% |

### 对玩家体验的影响

| 体验指标 | 说明 |
| :--- | :--- |
| 视野范围 | 在性能允许时可以看得更远 |
| 移动流畅度 | 减少了因区块加载导致的卡顿 |
| 加载等待 | 新区域加载更加渐进平滑 |
| 整体 FPS | 客户端因接收到的区块数据更合理而更流畅 |

[!NOTE]
SeeMore 的性能优化效果会根据服务器当前在线人数、玩家分布密度和硬件配置等因素有所不同。在服务器高峰期，动态视距调节会更加明显。

## ⚙️ 配置说明

SeeMore 的配置文件位于 `plugins/SeeMore/config.yml`。

### 关键配置项

| 配置项 | 说明 | 默认值 |
| :--- | :--- | :--- |
| `max-view-distance` | 最大允许视距（区块数） | `12` |
| `min-view-distance` | 最小视距（区块数） | `4` |
| `target-tps` | 目标 TPS 值 | `19.5` |
| `dynamic-adjustment` | 是否启用动态调整 | `true` |
| `adjustment-interval` | 动态调整间隔（秒） | `30` |
| `async-loading` | 是否启用异步加载 | `true` |

### 管理员命令

| 命令 | 说明 | 权限要求 |
| :--- | :--- | :--- |
| `/seemore reload` | 重新加载配置 | `seemore.admin` |
| `/seemore stats` | 查看当前视距统计 | `seemore.admin` |
| `/seemore set <玩家> <视距>` | 临时设置玩家视距 | `seemore.admin` |

[!WARNING]
SeeMore 的视距设置不能超过服务器 `server.properties` 中 `view-distance` 设定的硬上限。如果需要提升最大视距，请同时修改服务端配置文件中的对应值。注意过高的视距设置会对服务器内存造成较大压力。
