# ViaAprilFools

> ViaAprilFools-4.2.3-SNAPSHOT | 愚人节版本彩蛋支持

ViaAprilFools 是一秋小镇服务器安装的愚人节彩蛋插件，它是 ViaVersion 系列的一部分。该插件允许服务器在愚人节期间支持 Minecraft 历年愚人节版本的特性，为玩家带来有趣的游戏体验和怀旧乐趣。

## 📋 功能概览

| 功能 | 说明 |
| :--- | :--- |
| 愚人节版本支持 | 支持连接使用愚人节版本的客户端 |
| 版本自动识别 | 自动检测客户端的愚人节版本并正确处理 |
| 协议转换 | 将愚人节版本的协议转换为本服务器的版本协议 |
| 多版本兼容 | 同时支持多个不同年份的愚人节版本 |
| 自动更新 | 通过 AutoViaUpdater 自动获取最新兼容版本 |

## 🎭 支持的愚人节版本

Minecraft 每年愚人节都会发布一个带有有趣特性的特殊版本。ViaAprilFools 让这些版本的客户端能够连接到一秋小镇服务器。

### 历年愚人节版本

| 年份 | 版本名称 | 主要有趣特性 |
| :--- | :--- | :--- |
| 2013 | 2.0 | 粉色温蒂、红色石头 |
| 2014 | 15w14a | 无限维度跳跃 |
| 2015 | 1.RV-Pre1 | 更好的玻璃 |
| 2016 | 1.RV-Pre1 | 秘密房间 |
| 2019 | 19w14a | 投票版 |
| 2020 | 20w14∞ | 无限维度 |
| 2022 | 22w13oneblockatatime | 每次只能拿走一个物品 |
| 2023 | 23w13a_or_b | 投票系统（选择你的世界） |
| 2024 | 24w14potato | 马铃薯相关特性 |

[!TIP]
每年愚人节期间（4 月 1 日前后），Mojang 会发布一个带有特殊有趣特性的快照版本。你可以下载这些特殊版本的客户端，通过 ViaAprilFools 连接到一秋小镇服务器，体验这些有趣的功能与正常服务器内容的结合。

## 🔧 工作原理

ViaAprilFools 通过协议转换实现愚人节版本客户端与正常服务器的通信：

| 步骤 | 说明 |
| :--- | :--- |
| 1. 客户端连接 | 愚人节版本客户端尝试连接服务器 |
| 2. 版本检测 | ViaVersion 系列检测到客户端使用愚人节版本 |
| 3. 协议转换 | ViaAprilFools 将愚人节协议转换为标准协议 |
| 4. 服务器接受 | 服务器将客户端作为普通玩家接受 |
| 5. 正常游戏 | 玩家在服务器中正常游玩 |

### 与 ViaVersion 系列的协作

ViaAprilFools 是 ViaVersion 插件生态的一部分，需要配合以下插件工作：

| 插件 | 作用 |
| :--- | :--- |
| ViaVersion | 核心版本转换，支持新版客户端连接 |
| ViaBackwards | 向后兼容，支持旧版客户端连接 |
| ViaRewind | 更深层的旧版协议回退支持 |
| ViaAprilFools | 处理愚人节版本的特殊协议 |
| AutoViaUpdater | 自动更新 Via 系列插件 |
| ViaVersionStatus | 显示 Via 系列的运行状态 |

[!NOTE]
ViaAprilFools 是被动型插件，不需要玩家或管理员进行任何特殊操作。它在后台自动工作，当有愚人节版本客户端连接时自动激活对应的协议转换。管理员只需确保插件已正确安装即可。

## ⚠️ 使用须知

| 事项 | 说明 |
| :--- | :--- |
| 客户端版本 | 仅愚人节快照版本的客户端有效 |
| 协议限制 | 部分愚人节版本的特性可能无法完全转换 |
| 游戏体验 | 使用愚人节版本可能导致部分功能异常 |
| 非必需 | ViaAprilFools 是趣味性插件，不影响正常游戏 |

[!WARNING]
愚人节版本是 Mojang 发布的恶搞版本，部分功能是不完整的或有意设计的恶搞内容。使用愚人节版本连接服务器时，可能会遇到一些奇怪的行为，这是正常现象。如果你需要正常的游戏体验，请使用标准的 Minecraft 客户端。

[!TIP]
如果你想体验愚人节版本，可以在 Minecraft 启动器中启用「启用快照」选项，然后在版本列表中选择以愚人节命名的快照版本进行下载和安装。
