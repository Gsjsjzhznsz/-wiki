# SquareMap 在线地图

SquareMap 是一秋小镇服务器的实时在线地图系统，通过 Web 浏览器即可查看服务器的完整地图。地图会随玩家活动和服务器变化实时更新，是探索、导航和领地规划的重要工具。

## 访问地址

| 项目 | 内容 |
|:-----|:-----|
| **地图网址** | `https://map.yiqiu.example.com` |
| 支持设备 | 电脑浏览器、手机浏览器、平板 |
| 更新频率 | 每 2 秒渲染一次玩家位置 |
| 地图样式 | 带光影着色的 2D 俯视图 |

[!TIP]
建议将地图网址**添加到浏览器书签**，方便随时查看。手机端可以添加到主屏幕作为快捷方式，体验类似原生 App。

## 核心功能

### 实时地图渲染

SquareMap 使用服务端的区块数据实时渲染地图瓦片，无需第三方地图服务支持。

| 功能 | 说明 |
|:-----|:-----|
| 多世界支持 | 独立展示主世界、下界、末地的地图 |
| 瓦片渲染 | 基于 256×256 像素瓦片的分层渲染系统 |
| 光影着色 | 根据方块类型自动着色，区分草地、水域、沙地等 |
| 高度着色 | 可选的高度图模式，用颜色深浅表示地形高低 |
| 自动更新 | 已探索区域的地图随世界变化自动刷新 |

### 玩家追踪

| 功能 | 说明 |
|:-----|:-----|
| 实时位置 | 地图上显示所有在线玩家的实时位置标记 |
| 玩家头像 | 每个玩家标记使用其皮肤头像 |
| 隐身模式 | 启用隐身的玩家不会在地图上显示 |
| 点击定位 | 点击玩家头像可自动将地图居中到该玩家位置 |
| 方向指示 | 玩家标记带有朝向箭头，指示面朝方向 |

[!NOTE]
玩家在地图上的位置更新间隔为 **2 秒**。由于网络延迟，地图上的位置可能比游戏内实际位置略有滞后，这是正常现象。

### 区块渲染控制

| 渲染状态 | 图标 | 说明 |
|:-----|:-----|:-----|
| 已渲染 | ✅ 绿色 | 该区域地图已生成并可查看 |
| 渲染中 | 🔄 黄色 | 该区域正在渲染中 |
| 未渲染 | ❌ 灰色 | 该区域尚未被玩家探索，无法查看 |

[!WARNING]
**未探索的区域在地图上显示为灰色**。SquareMap 不会泄露未探索区域的地形信息。只有玩家实际探索过的区块才会被渲染到地图上。

### 标记系统

地图支持管理员在地图上添加自定义标记点，方便标注重要地点。

| 标记类型 | 图标 | 用途 |
|:-----|:-----|:-----|
| 出生点 | 🏠 | 服务器出生点位置 |
| 商业区 | 🏪 | 商店和交易区域 |
| 传送点 | 🚀 | 公共传送设施 |
| 资源区 | ⛏️ | 公共资源采集区 |
| 活动 | 🎉 | 活动举办地点 |
| 危险区 | ⚠️ | 危险区域或 PVP 区域 |

## 操作指南

### 地图导航

| 操作 | 电脑 | 手机 |
|:-----|:-----|:-----|
| 平移地图 | 鼠标拖拽 | 单指滑动 |
| 缩放 | 鼠标滚轮 | 双指捏合 |
| 查看坐标 | 鼠标悬停（左下角显示） | 长按（弹出坐标信息） |
| 查看玩家信息 | 点击玩家头像 | 点击玩家头像 |
| 切换世界 | 左上角世界选择器 | 左上角世界选择器 |

### 用于导航

1. **确定目标位置** → 在地图上找到你想前往的地点，记录坐标（X, Z）
2. **计算方向** → 使用 F3 打开调试界面，对比当前坐标与目标坐标
3. **使用导航** → 如果安装了导航 Mod（如 JourneyMap），可以直接将坐标设置为航点
4. **传送辅助** → 如果有传送权限，可以使用 `/tpa` 或传送点快速到达附近位置

### 用于领地规划

| 步骤 | 操作 |
|:-----|:-----|
| 1. 查看地形 | 在地图上浏览未占用的区域，寻找合适的建筑用地 |
| 2. 评估范围 | 使用缩放功能查看地形的细节，评估平坦度、水源位置等 |
| 3. 规划边界 | 记录计划领地的四角坐标 |
| 4. 申请领地 | 使用记录的坐标通过领地系统申请 |
| 5. 跟踪进度 | 在地图上实时查看领地内的建设进度 |

[!TIP]
SquareMap 的地图视图非常适合在开始大型建筑项目前进行**地形勘测**。通过缩放查看地形细节，可以避免在实地考察时浪费时间。

## 常见问题

### 地图显示空白？

- 确认该区域已被玩家**实际探索过**（进入过该区块的渲染范围）
- 如果刚探索了新区块，地图可能需要 **1-2 分钟** 的渲染时间
- 尝试刷新浏览器页面
- 检查是否选择了正确的世界（主世界/下界/末地）

### 玩家标记不更新？

- 玩家标记每 **2 秒** 更新一次，短暂延迟是正常的
- 如果超过 10 秒未更新，可能是服务器与地图之间的通信延迟
- 尝试刷新页面

### 如何在手机上获得更好的体验？

- 在浏览器菜单中选择「添加到主屏幕」，创建地图快捷方式
- 横屏使用可以获得更大的地图视野
- 使用 Wi-Fi 连接以获得更快的瓦片加载速度

### 地图可以下载离线使用吗？

不可以。SquareMap 是实时在线地图，所有地图数据都需要从服务器获取。不过你可以在浏览器中缓存已加载的瓦片，短期内离线仍可查看已浏览过的区域。
