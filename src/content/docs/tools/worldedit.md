# WorldEdit 建筑辅助

WorldEdit 是 Minecraft 服务器端最经典的建筑辅助插件，为建筑师提供强大的选区操作、方块填充、结构复制粘贴等功能。在一秋小镇服务器中，WorldEdit 已适配 **Folia** 多线程架构，确保在高并发环境下依然稳定运行。

同时服务器搭配了 **WorldEditSelectionVisualizer-2.1.10** 选区可视化插件，让选区范围一目了然，大幅降低建筑失误率。

## 基础工具

### 木斧选区工具

WorldEdit 使用木斧（Wooden Axe）作为核心选区工具，通过左键和右键设定选区的两个对角点。

| 命令 | 说明 | 权限要求 |
|:-----|:-----|:---------|
| `//wand` | 获取木斧选区工具 | `worldedit.wand` |
| 左键点击方块 | 设置选区第一个点（位置 A） | — |
| 右键点击方块 | 设置选区第二个点（位置 B） | — |

[!TIP]
在生存模式下也可以使用 `//wand` 获取木斧。木斧不会覆盖你手中的物品——它会直接给予一把新的木斧。如果不慎丢失，随时可以重新获取。

## 核心命令参考

### 选区操作命令

| 命令 | 说明 | 示例 |
|:-----|:-----|:-----|
| `//expand <数量> <方向>` | 向指定方向扩展选区 | `//expand 10 up` |
| `//contract <数量> <方向>` | 向指定方向收缩选区 | `//contract 5 north` |
| `//shift <数量> <方向>` | 平移选区（不改变大小） | `//shift 3 down` |
| `//outset <数量>` | 向外扩展选区（所有方向） | `//outset 2` |
| `//inset <数量>` | 向内收缩选区（所有方向） | `//inset 1` |
| `//count <方块>` | 统计选区内指定方块数量 | `//count stone` |
| `//size` | 查看当前选区体积与尺寸 | — |

### 方块操作命令

| 命令 | 说明 | 示例 |
|:-----|:-----|:-----|
| `//set <方块>` | 将选区内所有方块设为指定方块 | `//set stone` |
| `//replace <旧方块> <新方块>` | 替换选区内方块 | `//replace dirt grass_block` |
| `//copy` | 复制当前选区内容到剪贴板 | — |
| `//paste [-a]` | 粘贴剪贴板内容（`-a` 不粘贴空气） | `//paste -a` |
| `//cut` | 剪切选区内容到剪贴板 | — |
| `//rotate <角度>` | 旋转剪贴板内容 | `//rotate 90` |
| `//flip <方向>` | 翻转剪贴板内容 | `//flip up` |
| `//undo` | 撤销上一步操作 | — |
| `//redo` | 重做上一步撤销的操作 | — |

[!NOTE]
`//undo` 和 `//redo` 支持多步回退，默认保留最近 **100 步**操作历史。在大型建筑项目中，建议每完成一个结构就执行一次 `//copy` 作为备份。

### 几何体生成命令

| 命令 | 说明 | 示例 |
|:-----|:-----|:-----|
| `//sphere <方块> <半径> [-h]` | 生成实心球体（`-h` 为空心） | `//sphere glass 5 -h` |
| `//cyl <方块> <半径> <高度> [-h]` | 生成实心圆柱（`-h` 为空心） | `//cyl oak_log 3 10 -h` |
| `//hsphere <方块> <半径>` | 生成空心球体（简写） | `//hsphere glass 5` |
| `//hcyl <方块> <半径> <高度>` | 生成空心圆柱（简写） | `//hcyl stone 4 8` |
| `//pyramid <方块> <大小> [-h]` | 生成金字塔 | `//pyramid sand 5 -h` |

[!TIP]
使用几何体命令前，建议先用 `//sel` 清除旧选区，避免误操作覆盖已有建筑。生成大型几何体时留意服务器 TPS，避免一次性生成过大的结构。

### 区域工具命令

| 命令 | 说明 | 示例 |
|:-----|:-----|:-----|
| `//drain <半径>` | 排水（移除水源/岩浆） | `//drain 15` |
| `//fill <半径> <方块>` | 填充凹陷区域 | `//fill 10 water` |

| `//removebelow <大小> <深度>` | 移除脚下方块 | `//removebelow 1 10` |
| `//naturalize` | 自然化选区（草-泥土-石头） | — |
| `//green` | 在选区表面铺设草方块 | — |

## 选区可视化

### WorldEditSelectionVisualizer-2.1.10

WorldEdit 原生的选区仅通过粒子效果和聊天栏文字提示边界，在大型选区中很难精确判断范围。一秋小镇服务器额外安装了 **WorldEditSelectionVisualizer** 插件，提供直观的选区可视化效果。

#### 可视化功能

| 功能 | 说明 |
|:-----|:-----|
| 选区边框渲染 | 使用半透明方块或粒子线条勾勒选区边框 |
| 实时更新 | 修改选区时可视化即时刷新，无需手动操作 |
| 多选区支持 | 同时显示多个玩家的选区，互不干扰 |
| 性能优化 | 基于区域检测渲染，仅在玩家附近绘制粒子 |

[!NOTE]
选区可视化效果为客户端渲染，不同模组/光影包可能会影响显示效果。如遇显示异常，请尝试关闭光影或切换到默认资源包查看。

## Folia 兼容性说明

一秋小镇服务器运行在 **Folia** 多线程架构上。原版 WorldEdit 并非原生支持 Folia，需要使用经过 Folia 补丁的构建版本。

| 兼容性项目 | 说明 |
|:-----|:-----|
| 区域调度 | WorldEdit 操作会被正确调度到对应区域线程，不会导致线程安全问题 |
| 异步操作 | 大规模方块操作使用异步任务，避免阻塞主区域线程 |
| 选区工具 | 木斧交互事件已适配 Folia 的事件分发机制 |
| 剪贴板 | 粘贴操作自动计算目标区域并调度到正确的区域线程 |

[!WARNING]
在 Folia 环境下，**不要**在跨区域选区上执行 `//set` 等大批量操作。如果选区跨越了多个 Folia 区域（Region），可能导致操作延迟或部分方块未生效。建议将大型操作拆分为单区域内的操作。

## 建筑师使用指南

### 典型工作流程

1. **规划** → 使用 `//wand` 获取木斧，标定建筑区域范围
2. **地基** → 使用 `//set stone` 铺设基础平台
3. **地形** → 使用 `//naturalize` 或 `//green` 处理地表
4. **结构** → 手动搭建主体结构，使用 `//copy` / `//paste` 复制对称部分
5. **装饰** → 使用 `//sphere`、`//cyl` 等命令生成穹顶、柱子等装饰元素
6. **修正** → 使用 `//undo` 撤销错误操作，使用 `//replace` 批量替换方块

### 性能建议

| 操作规模 | 建议单次最大方块数 | 说明 |
|:-----|:-----|:-----|
| 小型操作 | ≤ 10,000 | 安全范围，不会影响服务器性能 |
| 中型操作 | ≤ 100,000 | 可能有短暂延迟，建议在低峰时段操作 |
| 大型操作 | ≤ 1,000,000 | 必须分批次操作，注意服务器 TPS |
| 超大型操作 | > 1,000,000 | 禁止单次操作，请联系管理员使用脚本分批处理 |

[!WARNING]
单次 `//set` 或 `//replace` 操作超过 **100 万方块**会自动被服务器拦截。如需进行超大规模地形改造，请联系管理员申请执行权限或使用后台脚本分批处理。

## 常见问题

### 木斧无法选区？

- 确认你手持的是**木斧**（Wooden Axe），而不是石斧或其他工具
- 检查是否有其他插件覆盖了左键/右键交互事件
- 尝试重新执行 `//wand` 获取新的木斧

### 粘贴位置不对？

- 剪贴板的粘贴原点是你执行 `//copy` 时**所在的位置**
- 可使用 `//rotate` 和 `//flip` 调整剪贴板方向后再粘贴
- 粘贴前可以先 `//paste -a` 预览效果（不含空气方块）

### 操作卡住没有响应？

- 大型操作需要时间处理，请耐心等待
- 如果超过 30 秒没有响应，使用 `//undo` 尝试回退
- Folia 环境下跨区域操作可能出现延迟，这是正常现象
