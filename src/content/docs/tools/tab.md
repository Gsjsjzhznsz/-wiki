# TAB 信息面板

TAB（TAB v6.1.0）是一秋小镇服务器使用的玩家列表与信息面板自定义插件。它全面接管了 Minecraft 的 Tab 列表（按 `Tab` 键显示的玩家列表）、计分板侧边栏、Boss 血条和名称下方信息栏，为玩家提供一致且美观的 UI 体验。

## 功能模块

TAB 插件提供以下四大显示模块，每个模块都可以独立配置：

| 模块 | 说明 | 服务器状态 |
|:-----|:-----|:-----|
| **Tab 列表** | 自定义 Tab 键显示的玩家列表格式 | ✅ 已启用 |
| **计分板侧边栏** | 屏幕右侧的实时信息面板 | ✅ 已启用 |
| **Boss 血条** | 屏幕顶部的滚动信息条 | ✅ 已启用 |
| **名称下方** | 玩家名称下方显示自定义信息 | ✅ 已启用 |

[!TIP]
所有显示模块均支持 **PlaceholderAPI** 变量，这意味着显示的信息可以动态变化——如实时 TPS、在线人数、玩家坐标等。

## Tab 列表

### 显示内容

按 `Tab` 键后，玩家列表会显示以下信息：

| 列 | 内容 | 示例 |
|:-----|:-----|:-----|
| 头像列 | 玩家头像 | 玩家皮肤头像 |
| 名称列 | 玩家昵称 + 前缀后缀 | `§a[居民] §fSteve` |
| 信息列 | Ping 值 | `§715ms` |
| 信息列 | 当前所在世界 | `§7主世界` |

### Tab 列表布局

```
┌──────────────────────────────────────┐
│  §l§6一秋小镇 §7| §f在线: §a12/100  │

│  §e[访客] §fHerobrine §7末地  §715ms│
│  ...                                  │
└──────────────────────────────────────┘
```

## 计分板侧边栏

### 显示内容

屏幕右侧的计分板会实时显示以下信息：

| 行数 | 显示内容 | 说明 |
|:-----|:-----|:-----|
| 标题 | `§l§6一秋小镇` | 服务器名称 |
| 第 1 行 | `§7--------` | 分隔线 |
| 第 2 行 | `§f在线: §a%server_online%` | 当前在线人数 |
| 第 3 行 | `§fTPS: §a%server_tps%` | 服务器 TPS |
| 第 4 行 | `§f坐标: §7%x% %y% %z%` | 玩家当前坐标 |
| 第 5 行 | `§f世界: §7%world%` | 当前所在世界 |
| 第 6 行 | `§f金币: §e%money%` | 玩家金币余额 |
| 第 7 行 | `§f游戏时间: §7%time_played%` | 累计在线时长 |
| 第 8 行 | `§7--------` | 分隔线 |
| 第 9 行 | `§7www.yiqiu.example.com` | 服务器网站 |

[!NOTE]
计分板内容会**每秒自动刷新**。坐标、TPS 等实时数据的变化会立即反映在侧边栏中。

## Boss 血条

屏幕顶部的 Boss 血条用于显示滚动通知或重要信息：

| 显示内容 | 刷新频率 | 说明 |
|:-----|:-----|:-----|
| 服务器公告 | 每 30 秒轮换 | 滚动显示服务器规则、活动通知等 |
| 欢迎消息 | 玩家加入时 | `欢迎 %player% 来到一秋小镇！` |
| 活动提醒 | 活动开始前 5 分钟 | `§c红石大赛将在 5 分钟后开始！` |

[!WARNING]
Boss 血条与 Minecraft 原版的 Boss 血条（如末影龙、凋灵的血条）可能会发生冲突。当玩家处于 Boss 战时，插件的 Boss 血条会自动隐藏，避免遮挡战斗信息。

## 名称下方信息

在玩家名称下方（名称标签下方）会显示一行简短信息：

| 信息 | 格式 | 示例 |
|:-----|:-----|:-----|
| 称号 | 前缀标签 | `§b✦ 建筑大师` |
| 坐标 | 简略坐标 | `§7[120, 64, -45]` |

[!TIP]
名称下方信息在玩家距离较远时会自动隐藏，以确保远距离时名称标签不会被信息文字遮挡。

## PlaceholderAPI 集成

TAB 插件深度集成了 PlaceholderAPI，支持所有已安装的 PlaceholderAPI 扩展变量。以下是一秋小镇服务器中常用的变量：

| 变量 | 来源 | 说明 |
|:-----|:-----|:-----|
| `%server_online%` | PlaceholderAPI 内置 | 在线玩家数 |
| `%server_max_players%` | PlaceholderAPI 内置 | 最大玩家数 |
| `%server_tps%` | PlaceholderAPI 内置 | 服务器 TPS |
| `%player%` | PlaceholderAPI 内置 | 玩家名称 |
| `%world%` | PlaceholderAPI 内置 | 当前世界名称 |
| `%x%` / `%y%` / `%z%` | PlaceholderAPI 内置 | 玩家坐标 |
| `%money%` | Vault 扩展 | 玩家经济余额 |
| `%time_played%` | PlaceholderAPI 扩展 | 累计游戏时间 |
| `%luckperms_prefix%` | LuckPerms 扩展 | 权限组前缀 |
| `%afk%` | PlaceholderAPI 扩展 | AFK 状态 |

## 玩家体验提升

### 信息一致性

TAB 统一了所有信息显示的风格和颜色方案，确保玩家在任何界面看到的都是协调一致的视觉体验。管理员和居民的前缀颜色、信息格式都经过精心设计。

### 减少命令依赖

通过 TAB 侧边栏，玩家无需频繁输入 `/bal`、`/tps`、`/coords` 等命令即可获取关键信息。所有常用数据都在侧边栏实时展示。

### 社交便利

Tab 列表中显示玩家所在世界和延迟，方便玩家了解好友的在线状态和游戏环境，促进社交互动。

## 常见问题

### Tab 列表显示异常？

- 确保你的客户端**没有安装**其他 Tab 列表修改模组（如 Tab-Fabric），否则可能冲突
- 尝试按 `Tab` 键多次或重新连接服务器
- Mod 端客户端与插件端的数据同步有极小概率延迟，通常在 1-2 秒内自动修正

### 侧边栏不显示？

- 检查游戏设置中的「计分板」显示选项是否开启
- 某些 Mod 可能会覆盖侧边栏显示位置
- 使用 `/tab reload` 命令（如有权限）可手动刷新

### Boss 血条信息滚动太快？

- Boss 血条的滚动速度由服务器统一控制，当前设置为每 30 秒切换
- 如果觉得信息难以阅读，可以关注侧边栏中的静态信息作为替代
