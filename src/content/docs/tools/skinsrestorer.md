# SkinsRestorer 皮肤修复

SkinsRestorer 是一秋小镇服务器安装的皮肤管理插件，解决玩家皮肤加载失败、皮肤丢失等问题，同时支持通过 Geyser 实现基岩版与 Java 版的跨端皮肤同步。

## 功能概述

| 功能 | 说明 |
|:-----|:-----|
| 皮肤恢复 | 自动检测并修复皮肤加载失败的情况 |
| 自定义皮肤 | 允许玩家通过命令设置任意正版皮肤 |
| URL 皮肤 | 支持通过图片 URL 加载自定义皮肤 |
| Geyser 集成 | 基岩版玩家可显示 Java 版皮肤 |
| 皮肤缓存 | 服务端缓存皮肤数据，减少对外部 API 的请求 |
| 自动更新 | 皮肤变更后自动推送给附近玩家 |

[!TIP]
SkinsRestorer 的皮肤缓存系统会自动管理已加载的皮肤数据。当服务器重启后，缓存中的皮肤数据会保留，无需玩家重新设置。

## 皮肤设置命令

### /skin 命令

| 命令 | 说明 | 示例 |
|:-----|:-----|:-----|
| `/skin set <玩家名>` | 设置为指定正版玩家的皮肤 | `/skin set Notch` |
| `/skin set url <链接>` | 通过 URL 设置自定义皮肤 | `/skin set url https://...` |
| `/skin clear` | 恢复为默认皮肤（Steve/Alex） | — |
| `/skin update` | 强制刷新当前皮肤 | — |
| `/skin <玩家名>` | 快捷设置皮肤（`set` 的简写） | `/skin Notch` |

### 皮肤管理命令

| 命令 | 说明 | 权限要求 |
|:-----|:-----|:-----|
| `/skin clear <玩家名>` | 清除其他玩家的自定义皮肤 | `skinsrestorer.admin` |
| `/skin set <玩家名> <皮肤名>` | 为其他玩家设置皮肤 | `skinsrestorer.admin` |
| `/skin update <玩家名>` | 强制刷新其他玩家皮肤 | `skinsrestorer.admin` |
| `/sr reload` | 重载 SkinsRestorer 配置 | `skinsrestorer.admin` |
| `/sr drop <玩家名>` | 清除指定玩家的皮肤缓存 | `skinsrestorer.admin` |

## 皮肤来源

### 正版玩家名

最常用且最可靠的皮肤设置方式。SkinsRestorer 会从 Mojang 官方皮肤服务器获取指定玩家名的皮肤数据。

| 项目 | 说明 |
|:-----|:-----|
| 命令格式 | `/skin set <正版玩家名>` |
| 皮肤来源 | Mojang 官方皮肤 API |
| 皮肤类型 | 支持经典（64×64）和Slim（64×64）两种模型 |
| 前提条件 | 该玩家名必须在 Mojang 系统中存在 |
| 可靠性 | ⭐⭐⭐⭐⭐ |

[!NOTE]
如果目标玩家更换了自己的皮肤，你需要重新执行 `/skin update` 命令来获取最新的皮肤数据。服务器缓存不会自动检测外部皮肤变化。

### URL 自定义皮肤

通过直接提供皮肤图片的 URL 来设置自定义皮肤，适用于使用非正版皮肤站生成的皮肤。

| 项目 | 说明 |
|:-----|:-----|
| 命令格式 | `/skin set url <图片URL>` |
| 图片要求 | 64×64 像素 PNG 格式，经典或 Slim 模型 |
| 支持协议 | `https://` 和 `http://` |
| 图片大小限制 | 不超过 1MB |
| 可靠性 | ⭐⭐⭐ |

[!WARNING]
URL 皮肤存在以下限制：
- 图片**必须**为 64×64 像素的标准 Minecraft 皮肤格式
- 服务器会下载并验证图片，不符合格式会被拒绝
- 某些图片托管服务可能阻止服务器端的下载请求
- 建议使用知名的皮肤站（如 MinecraftSkins、NameMC、Laby.net）的直链

### 推荐皮肤网站

| 网站 | 网址 | 说明 |
|:-----|:-----|:-----|
| NameMC | `namemc.com` | 全球最大的皮肤站，支持按分类浏览 |
| MinecraftSkins | `minecraftskins.com` | 丰富的皮肤库 |
| Laby.net | `labymod.net/skins` | LabyMod 官方皮肤站 |
| Minecraft Skin | `minersneedcoolshoes.com` | 支持在线皮肤编辑器 |
| MCSkinHistory | `mcskinhistory.com` | 可查看皮肤历史记录 |

## Geyser 跨端皮肤同步

一秋小镇服务器通过 **GeyserMC** 支持基岩版（Bedrock）玩家加入服务器。SkinsRestorer 的 Geyser 集成确保基岩版玩家也能显示和使用自定义皮肤。

### 工作原理

```
Java 版玩家设置皮肤
        ↓
SkinsRestorer 保存皮肤数据
        ↓
Geyser 读取皮肤数据
        ↓
转换为基岩版皮肤格式
        ↓
基岩版玩家可正常显示
```

### 跨端皮肤兼容性

| 场景 | 说明 |
|:-----|:-----|
| 基岩版 → 查看 Java 版皮肤 | ✅ 完全支持，自动转换格式 |
| 基岩版 → 设置自定义皮肤 | ⚠️ 需使用 `/skin set <名称>` 命令 |
| Java 版 → 查看基岩版皮肤 | ✅ 自动同步基岩版玩家皮肤 |
| 基岩版玩家自带皮肤 | ✅ 首次加入时使用基岩版自带皮肤 |

[!TIP]
基岩版玩家首次加入服务器时，系统会尝试使用其在 Xbox Live 上的头像作为默认皮肤。如果加载失败，会回退到 Steve 或 Alex 默认皮肤。之后可以通过 `/skin set` 命令设置任意皮肤。

## 常见问题

### 皮肤设置后不显示？

- 执行 `/skin update` 强制刷新
- 如果附近有其他玩家，他们可能需要重新进入你的渲染范围才能看到更新
- 某些客户端 Mod（如 OptiFine 的自定义披风）可能覆盖皮肤显示
- 尝试退出服务器重新进入

### 提示「皮肤解析失败」？

- 检查 URL 是否可从外部访问（在浏览器中打开确认）
- 确认图片为 **64×64 PNG** 格式
- 检查图片文件大小是否超过 1MB
- 尝试将图片上传到其他托管服务后重试

### 基岩版玩家看不到自己的皮肤？

- 基岩版客户端有独立的皮肤缓存，可能需要**重启游戏**才能看到变化
- 确认已在服务器中执行了 `/skin set` 命令
- 在基岩版设置中检查「自定义皮肤」选项是否开启
- 某些基岩版版本对服务器下发皮肤的支持存在差异

### 多人同时设置皮肤导致延迟？

SkinsRestorer 的皮肤请求会经过服务端缓存队列。在多人同时设置皮肤的极端情况下（如服务器刚重启），可能会有数秒的排队延迟。这是正常现象，请求不会被丢弃，只是需要等待处理。

### 皮肤在特定 Mod 中显示异常？

- **OptiFine**：OptiFine 的自定义功能可能与 SkinsRestorer 冲突，尝试禁用 OptiFine 的自定义皮肤选项
- **Sodium**：Sodium 通常与 SkinsRestorer 兼容良好
- **LabyMod**：LabyMod 有自己的皮肤系统，可能覆盖服务器下发的皮肤
- 如果使用客户端皮肤 Mod，建议优先在 Mod 设置中关闭「自定义皮肤」功能，以服务器皮肤为准
