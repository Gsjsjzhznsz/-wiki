# SuperHarvest 连锁采集

SuperHarvest 是一秋小镇服务器安装的连锁采集插件，允许玩家通过一次挖掘自动破坏相连的同类型方块。无论是挖矿、伐木还是收割农作物，SuperHarvest 都能大幅减少重复操作，让资源采集效率成倍提升。

## 功能概述

### 核心机制

SuperHarvest 的核心原理是**连通方块链式破坏**：当你挖掘一个方块时，插件会自动检测与之相连（六面相邻）的同类型方块，并将它们一并破坏。破坏的方块掉落物会直接进入玩家背包，超出的部分自动掉落在玩家脚下。

| 特性 | 说明 |
|:-----|:-----|
| 连锁挖矿 | 挖掘矿石时自动破坏相连的同种矿石 |
| 连锁伐木 | 砍伐树木时自动破坏整棵树的木头 |
| 连锁收割 | 收割农作物时自动收割相连的同种作物 |
| 智能检测 | 仅破坏物理相连的同类方块，不会误伤隔壁矿脉 |
| 背包优先 | 掉落物优先进入背包，避免物品散落 |

[!TIP]
连锁采集**不需要**任何特殊工具或附魔。你只需要像平常一样挖掘方块，插件会自动处理连锁逻辑。当然，拥有「时运」附魔的工具依然会正常生效，连锁破坏的每个方块都会独立计算时运掉落。

## 配置参数

以下是服务器当前 SuperHarvest 的核心配置参数：

| 配置项 | 当前值 | 说明 |
|:-----|:-----|:-----|
| `max-chain-size` | `64` | 单次连锁最大方块数 |
| `chain-mining-enabled` | `true` | 是否启用连锁挖矿 |
| `chain-woodcutting-enabled` | `true` | 是否启用连锁伐木 |
| `chain-farming-enabled` | `true` | 是否启用连锁收割 |
| `tool-durability-consumption` | `per-block` | 耐久消耗模式（`per-block` / `per-chain`）|
| `drop-to-inventory` | `true` | 掉落物是否直接进入背包 |
| `particles-enabled` | `true` | 是否显示连锁破坏粒子效果 |
| `sound-enabled` | `true` | 是否播放连锁破坏音效 |

[!WARNING]
当前耐久消耗模式为 **`per-block`**（逐方块消耗）。这意味着连锁破坏 10 个石头会消耗工具 10 点耐久。请注意工具耐久，避免工具在连锁过程中损坏导致操作中断。

## 对红石材料采集的帮助

在一秋小镇服务器中，红石电路是许多建筑和机关的核心。SuperHarvest 在红石材料采集方面提供以下便利：

### 1. 红石矿石快速采集

挖掘红石矿石时，整个矿脉会被一次性破坏，大幅减少在矿洞中的停留时间。对于需要大量红石粉的复杂红石项目，效率提升尤为明显。

### 2. 青金石批量获取

青金石通常成片出现，连锁采集可以快速清空整个青金石矿层。

### 3. 石英高效收集

下界石英是红石比较器和日光传感器的重要材料。下界中的石英矿脉往往规模较大，连锁采集可以在数秒内完成原本需要数分钟的工作。

### 4. 甘蔗与竹子自动化辅助

甘蔗和竹子是制作纸张、书籍、脚手架和红石中继器的原材料。SuperHarvest 可以一键收割整列甘蔗/竹子，配合自动种植机使用，实现高效的原材料循环。

| 红石相关材料 | 来源方块 | 连锁采集效率提升 |
|:-----|:-----|:-----|
| 红石粉 | 红石矿石 | ⭐⭐⭐⭐⭐ |
| 青金石 | 青金石矿石 | ⭐⭐⭐⭐ |
| 石英 | 下界石英矿石 | ⭐⭐⭐⭐⭐ |
| 纸张 | 甘蔗 | ⭐⭐⭐⭐⭐ |
| 脚手架 | 竹子 | ⭐⭐⭐⭐ |
| 比较器 | 石英 + 石头 | ⭐⭐⭐ |

## 常见问题

### 为什么有时候只破坏了一个方块？

- 连锁采集仅对**物理相连**（六面接触）的同类型方块生效
- 如果矿石之间有空气或石头隔开，不会触发连锁
- 检查是否超过了 `max-chain-size`（当前为 64）的限制

### 连锁采集会影响我的时运附魔吗？

不会。连锁破坏的每个方块都会**独立计算**附魔效果。你的时运 III 镐子对连锁破坏的每个钻石矿石都会生效，这意味着连锁采掘一个大型钻石矿脉可以获得远超正常数量的钻石。

### 可以在领地内使用连锁采集吗？

可以。SuperHarvest 尊重领地权限系统。只有当你在自己拥有建设权限的区域内时，连锁采集才会生效。在他人领地或公共保护区中，连锁功能会被自动禁用。

### 连锁采集会导致服务器卡顿吗？

正常使用不会。服务器对单次连锁操作设有 64 方块的上限，且所有破坏操作都在 Folia 的区域线程中异步执行。如果在使用过程中感觉到延迟，可能是同时有大量玩家在进行连锁操作，属于正常的服务器负载波动。
