# CompassCommand 指南针导航

CompassCommand 是一秋小镇服务器配备的指南针导航工具插件，完全兼容 **JE17**（Java Edition 1.17+）的资源包与物品渲染机制。该插件为普通的指南针物品赋予了强大的导航功能，支持指向坐标、追踪玩家和导航至自定义航点。

[!NOTE]
CompassCommand 仅对服务器内的指南针物品生效，不会影响客户端原版指南针的行为逻辑。所有导航计算在服务器端完成，确保结果的准确性。

---

## 功能概述

| 功能 | 说明 |
| :--- | :--- |
| **坐标导航** | 将指南针指针指向指定的世界坐标 |
| **玩家追踪** | 将指南针指针指向指定在线玩家的位置 |
| **航点导航** | 将指南针指针指向已保存的自定义航点 |
| **实时更新** | 指南针指针随玩家移动实时旋转更新方向 |
| **距离显示** | 在物品提示栏（Tooltip）中显示目标距离 |
| **跨维度检测** | 当目标位于不同维度时给出提示 |

---

## 基础用法

### 指向坐标

将手中或物品栏中的指南针指向指定坐标：

```
/compass point <x> <y> <z>
```

| 参数 | 必填 | 说明 |
| :--- | :---: | :--- |
| `<x>` | ✅ | 目标 X 坐标（支持相对坐标 `~`） |
| `<y>` | ✅ | 目标 Y 坐标（支持相对坐标 `~`） |
| `<z>` | ✅ | 目标 Z 坐标（支持相对坐标 `~`） |

**示例：**

```
/compass point 1024 64 -512
/compass point ~ ~ ~-100
```

[!TIP]
使用相对坐标（`~`）可以快速设置指南针指向你当前位置附近的方向。例如 `/compass point ~ ~ ~-100` 会将指南针指向你正南方 100 格处。

### 追踪玩家

将指南针指针指向指定在线玩家：

```
/compass track <玩家名>
```

| 参数 | 必填 | 说明 |
| :--- | :---: | :--- |
| `<玩家名>` | ✅ | 目标在线玩家的名称 |

[!WARNING]
只能追踪**在线玩家**。如果目标玩家下线或更换了世界，指南针会停止更新并提示目标丢失。同时，追踪其他玩家需对方未开启隐身模式，且目标不在设置了禁止追踪的领地内。

### 导航至航点

如果服务器配置了自定义航点，可以直接导航：

```
/compass waypoint <航点名称>
```

| 参数 | 必填 | 说明 |
| :--- | :---: | :--- |
| `<航点名称>` | ✅ | 预设航点的名称 |

## 与领地系统的关联

CompassCommand 在一秋小镇服务器中可以与 Dominion 领地系统配合使用，提升导航体验。

### 推荐使用场景

| 场景 | 操作 | 说明 |
| :--- | :--- | :--- |
| 前往好友领地 | `/compass track <玩家名>` | 追踪好友位置找到其领地 |
| 前往指定坐标 | `/compass point <x> <y> <z>` | 根据坐标导航至目标领地 |
| 返回基地 | 设置家后用 `/home` 传送 | 指南针适合短距离步行导航 |
| 探索时标记方向 | `/compass point <x> <y> <z>` | 标记感兴趣的地点方向 |

[!NOTE]
CompassCommand 仅提供**方向指引**，不会自动传送。如需精确传送，请使用 HuskHomes 系统的 `/home` 或 `/warp` 命令。

## 指南针显示信息

启用 CompassCommand 后，手持或悬浮在物品栏中的指南针会显示以下附加信息：

| 显示内容 | 格式 | 说明 |
| :--- | :--- | :--- |
| 目标类型 | `§e目标: 坐标 / 玩家 / 航点` | 当前指南针指向的目标类型 |
| 目标名称 | `§b名称: xxx` | 具体的目标标识 |
| 距离 | `§a距离: xxx 格` | 与目标的水平距离 |
| 维度 | `§c维度: overworld / nether / the_end` | 目标所在维度 |

[!TIP]
距离显示为**水平距离**（不考虑 Y 轴高度差），帮助你判断大致需要走多远。实际路程可能因地形高低起伏而有所不同。

---

## 跨维度行为

当指南针目标与玩家处于不同维度时，系统会进行特殊处理：

| 情况 | 行为 |
| :--- | :--- |
| 目标在同一维度 | ✅ 指南针正常指向目标方向，显示距离 |
| 目标在不同维度 | ⚠️ 指南针指针会随机旋转，并在提示栏显示目标所在维度 |
| 目标维度未知 | ❌ 提示无法确定目标位置 |

[!WARNING]
当目标位于不同维度时，指南针无法提供有效方向指引。此时建议先通过传送系统（如 `/warp` 或下界传送门）到达目标所在维度，再使用指南针进行精确导航。

## 常见问题

**Q: 指南针在末地能用吗？**

A: 可以。CompassCommand 在所有维度中均可正常工作。不过在末地中，由于缺乏原版指南针的参照点，CompassCommand 会完全接管指南针的显示逻辑。

**Q: 如何让指南针恢复正常行为？**

A: 执行 `/compass reset` 即可将指南针恢复为原版行为（指向世界出生点）。

**Q: 追踪的玩家下线了怎么办？**

A: 目标玩家下线后，指南针会保持最后一次已知方向，但提示栏会显示目标已离线。目标重新上线后，指南针会自动恢复实时追踪。

**Q: 指南针指向的坐标会随我的移动实时更新吗？**

A: 是的。只要指南针在你的物品栏中（不需要手持），指针方向就会随你的移动实时更新，确保你始终朝向正确方向。

[!TIP]
在大规模探索或远距离旅行时，建议将导航指南针放在快捷栏的固定位置（如第 9 格），这样无需切换物品即可在 HUD 上查看距离信息，保持高效导航。
