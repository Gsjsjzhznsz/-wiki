# HuskHomes 传送系统

HuskHomes 是一秋小镇服务器使用的传送与家标记插件，搭配 **HuskHomesGUI** 可视化界面，为玩家提供便捷的传送、家标记和公共传送点管理功能。该插件与 Dominion 领地系统深度集成，确保传送行为与领地权限协调一致。

[!NOTE]
HuskHomes 支持跨维度传送。你可以将家设置在下界或末地，传送时无需手动切换维度。

---

## 基础命令一览

| 命令 | 语法 | 说明 | 权限要求 |
| :--- | :--- | :--- | :---: |
| 设置家 | `/sethome <名称>` | 在当前位置设置一个家 | 默认拥有 |
| 传送到家 | `/home [名称]` | 传送到指定的家 | 默认拥有 |
| 删除家 | `/delhome <名称>` | 删除指定的家 | 默认拥有 |
| 请求传送 | `/tpa <玩家名>` | 请求传送到目标玩家 | 默认拥有 |
| 请求玩家来 | `/tpahere <玩家名>` | 请求目标玩家传送到你 | 默认拥有 |
| 返回上一次位置 | `/back` | 返回上一次传送前的位置 | 默认拥有 |
| 传送点 | `/warp <名称>` | 传送到公共传送点 | 默认拥有 |
| 列出所有家 | `/homes` | 列出你设置的所有家 | 默认拥有 |
| 列出传送点 | `/warps` | 列出所有公共传送点 | 默认拥有 |
| 传送请求接受 | `/tpaccept` | 接受收到的传送请求 | 默认拥有 |
| 传送请求拒绝 | `/tpdeny` | 拒绝收到的传送请求 | 默认拥有 |

## 家（Home）系统

### 设置家

在你想标记的位置执行以下命令：

```
/sethome <名称>
```

| 参数 | 必填 | 说明 |
| :--- | :---: | :--- |
| `<名称>` | ✅ | 家的名称，建议使用易记的英文名称 |

[!TIP]
建议为家使用有意义的名称，例如 `base`（基地）、`farm`（农场）、`mine`（矿场）、`nether_hub`（下界中转站）等，方便日后快速选择传送。

### 传送到家

```
/home [名称]
```

| 参数 | 必填 | 说明 |
| :--- | :---: | :--- |
| `[名称]` | ❌ | 如果省略名称且只有一个家，将直接传送；如果有多个家，将显示家列表供选择 |

### 删除家

```
/delhome <名称>
```

[!WARNING]
删除家操作**不可撤销**。删除后该家的坐标信息将被永久移除，请谨慎操作。

### 家数量限制

一秋小镇服务器对不同玩家组设置了不同的家数量上限：

| 玩家组别 | 家数量上限 | 说明 |
| :--- | :---: | :--- |
| 默认玩家 | 3 个 | 包含公开和私密家在内 |
| VIP 玩家 | 10 个 | 解锁更多家标记位 |
| 管理员 | 无限制 | 管理团队无上限限制 |

[!NOTE]
以上限制为服务器当前配置，可能随版本更新调整，请以服务器公告为准。

## 公开家与私密家

HuskHomes 支持将家设置为**公开**或**私密**状态，公开的家可以被其他玩家搜索和传送。

### 设置家为公开

```
/sethome <名称> public
```

### 设置家为私密

```
/sethome <名称> private
```

### 修改已有家的可见性

```
/home <名称> public
/home <名称> private
```

| 状态 | 说明 |
| :--- | :--- |
| **公开（public）** | 其他玩家可以通过 `/home <玩家名>:<家名称>` 传送到你的公开家 |
| **私密（private）** | 仅你自己可以传送到该家，其他玩家无法查看或访问 |

### 传送到其他玩家的公开家

```
/home <玩家名>:<家名称>
```

[!TIP]
如果你经营一家商店，可以将商店位置设为公开家，方便其他玩家快速找到你的店铺。例如 `/sethome shop public`，其他玩家即可通过 `/home 你的ID:shop` 前往。

## 传送请求（TPA）系统

TPA 系统允许玩家之间进行双向传送请求，需要对方同意后才会执行传送。

### 请求传送到目标玩家

```
/tpa <玩家名>
```

执行后，目标玩家将收到传送请求提示，需使用 `/tpaccept` 同意后你才会被传送过去。

### 请求目标玩家传送到你

```
/tpahere <玩家名>
```

执行后，目标玩家将收到请求提示，同意后该玩家会被传送到你的位置。

### 处理传送请求

| 命令 | 说明 |
| :--- | :--- |
| `/tpaccept` | 接受最新收到的传送请求 |
| `/tpdeny` | 拒绝最新收到的传送请求 |

[!WARNING]
传送请求有 **60 秒** 的有效期。超时后请求将自动失效，需要重新发送。每次只能处理一个待处理的传送请求。

## 返回功能（Back）

```
/back
```

`/back` 命令可以让你返回上一次传送前的位置。以下场景会记录你的上一个位置：

| 触发场景 | 说明 |
| :--- | :--- |
| 使用 `/home` 传送后 | `/back` 将带你回到传送出发的位置 |
| 使用 `/warp` 传送后 | `/back` 将带你回到传送出发的位置 |
| TPA 传送后 | `/back` 将带你回到传送前的位置 |
| 被管理员传送后 | `/back` 将带你回到被传送前的位置 |
| 死亡后 | 部分配置下 `/back` 可用于回到死亡位置 |

[!TIP]
`/back` 只记录一次位置。连续执行两次 `/back` 会在当前位置和上一次位置之间来回切换。

## 传送点（Warp）系统

传送点是由管理员创建的公共传送点，所有玩家均可使用。

### 使用传送点

```
/warp <名称>
```

### 列出所有传送点

```
/warps
```

常用传送点示例：

| 传送点名称 | 目标位置 | 说明 |
| :--- | :--- | :--- |
| `spawn` | 主城出生点 | 服务器主城，新手起始位置 |
| `shop` | 商业区 | 玩家商店聚集区域 |
| `farm_world` | 农业世界 | 公共农场区域 |
| `nether_hub` | 下界交通枢纽 | 下界快速旅行中转站 |

[!NOTE]
传送点列表可能随服务器发展持续更新，使用 `/warps` 可查看最新可用传送点。

## HuskHomesGUI 可视化界面

**HuskHomesGUI** 是搭配 HuskHomes 使用的可视化图形界面插件，让玩家通过点击 GUI 菜单来管理家和传送点，无需记忆命令。

### 打开 GUI

```
/homegui
```

或者直接执行无参数的 `/home` 命令，系统会自动弹出 GUI 界面。

### GUI 功能说明

| GUI 页面 | 功能 | 操作方式 |
| :--- | :--- | :--- |
| **家列表页** | 显示你所有的家 | 左键点击传送，右键点击编辑 |
| **传送点页** | 显示所有公共传送点 | 左键点击传送 |
| **设置家页** | 在当前位置设置新家 | 输入名称后点击确认 |
| **公开家浏览页** | 浏览其他玩家的公开家 | 左键点击传送 |

### GUI 操作说明

| 操作 | 说明 |
| :--- | :--- |
| **左键点击** | 执行主要操作（如传送） |
| **右键点击** | 执行次要操作（如编辑、删除确认） |
| **Shift + 左键** | 查看详细信息（坐标、世界等） |
| **翻页** | 点击界面底部的翻页按钮浏览更多项目 |

[!TIP]
GUI 界面会直观地显示家的坐标位置、所在世界和公开/私密状态。推荐新手玩家优先使用 GUI 管理家，等熟悉命令后再使用命令行操作以提高效率。

## 传送预热与冷却

为平衡游戏体验，HuskHomes 对部分传送操作设置了预热（Warmup）和冷却（Cooldown）时间。

### 时间设置

| 传送类型 | 预热时间 | 冷却时间 | 说明 |
| :--- | :---: | :---: | :--- |
| `/home` | 5 秒 | 30 秒 | 传送前需站立等待 5 秒 |
| `/warp` | 5 秒 | 30 秒 | 传送前需站立等待 5 秒 |
| `/tpa` | 无 | 60 秒 | 发送请求后需等待对方确认 |
| `/back` | 3 秒 | 15 秒 | 快速返回，预热较短 |

[!WARNING]
在预热期间**移动、受到伤害或执行其他命令**将导致传送**取消**。请确保在安全、静止的状态下发起传送。

### VIP 玩家特权

| 特权 | 默认玩家 | VIP 玩家 |
| :--- | :---: | :---: |
| `/home` 预热时间 | 5 秒 | 0 秒（即时传送） |
| `/warp` 预热时间 | 5 秒 | 0 秒（即时传送） |
| `/home` 冷却时间 | 30 秒 | 10 秒 |
| `/warp` 冷却时间 | 30 秒 | 10 秒 |

## 与 Dominion 领地系统的集成

HuskHomes 与 Dominion 领地系统深度集成，确保传送行为不会破坏领地保护规则。

### 跨领地传送规则

| 场景 | 行为 |
| :--- | :--- |
| 传送到自己领地内的家 | ✅ 正常传送，无限制 |
| 传送到他人领地内的公开家 | ✅ 正常传送（领地允许传送时） |
| 传送到他人领地且领地禁止传送 | ❌ 传送被拒绝，提示权限不足 |
| TPA 传送到他人领地内 | ✅ 正常传送（领地允许传送时） |
| 传送目标位置被方块占据 | ❌ 传送被拒绝，提示位置不安全 |
| 传送目标位置在虚空中 | ❌ 传送被拒绝，提示位置不安全 |

### 传送安全检查

HuskHomes 在执行传送前会进行以下安全检查：

1. **领地权限检查**：确认目标位置的领地允许你传送进入
2. **方块安全检查**：确认传送落点没有被方块占据
3. **虚空检查**：确认传送目标不在虚空区域
4. **危险区域检查**：确认目标位置不存在岩浆等危险方块

[!NOTE]
如果你的家设置在他人领地中，且领地主人关闭了 `teleport` 权限，你将无法通过 `/home` 传送到该位置。请提前与领地主人沟通协调权限设置。

## 常见问题

**Q: 传送预热期间可以喝水或吃东西吗？**

A: 可以。喝水和吃东西不会取消传送预热。但移动（包括走动、跳跃、游泳）会取消传送。

**Q: 我可以设置多个同名同名的家吗？**

A: 不可以。每个家的名称在你的账号下必须唯一。如果你设置了一个新家使用了已存在的名称，旧家将被覆盖。

**Q: 其他玩家传送到我的公开家后能做什么？**

A: 到达后，该玩家在你领地内的行为仍受 Dominion 领地权限控制。如果没有被信任或没有被授予相应权限，他们只能在你允许的范围内活动。

[!TIP]
合理利用公开家功能可以大大方便玩家之间的社交和交易。如果你有公共设施（如交易所、免费农场等），强烈建议将其设为公开家。
