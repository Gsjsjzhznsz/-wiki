# Dominion 领地保护

Dominion 是一秋小镇服务器使用的精准圈地领地保护插件，当前版本为 **4.8.4-release-lite**。该插件允许玩家圈定自己的领地范围，精细控制不同玩家和成员的各类交互权限，有效保护建筑、红石机器和容器免受破坏。

[!NOTE]
一秋小镇服务器已为每位玩家配置了默认的领地数量上限和面积限制。如需扩大领地或增加数量，请参阅服务器公告或联系管理团队。

---

## 核心概念

| 概念 | 说明 |
| :--- | :--- |
| **领地（Dominion）** | 由玩家圈定的一块矩形区域，拥有独立的权限体系 |
| **领地主人（Owner）** | 创建领地的玩家，拥有该领地的最高管理权限 |
| **信任玩家（Trusted）** | 被领地主人授权的玩家，可拥有主人指定的权限 |
| **子领地（Sub-dominion）** | 在已有领地内部创建的更小区域，用于划分不同权限分区 |
| **旗帜（Flag）** | 领地级别的功能开关，用于控制特定行为是否被允许 |

## 创建领地

### 第一步：获取圈地工具

使用以下命令获取领地选择工具：

```
/dt
```

执行后你将获得一把**木斧**，这是 Dominion 的领地选择工具。

[!TIP]
木斧仅在圈地时使用，不会影响其原有的斧头功能。你可以安全地将其放入物品栏中备用。

### 第二步：选定区域对角点

1. 手持木斧，**左键点击**区域的第一个角点（如：西北角）
2. 移动到对角位置，**右键点击**第二个角点（如：东南角）

系统会自动计算两点之间的矩形区域作为领地范围。

[!WARNING]
两个角点必须构成一个有效的矩形。如果两个点在同一水平线或垂直线上（即面积为 0），系统将拒绝创建领地。同时请确保领地范围不超过服务器规定的最大面积限制。

### 第三步：创建领地

```
/dominion create <领地名称>
```

| 参数 | 必填 | 说明 |
| :--- | :---: | :--- |
| `<领地名称>` | ✅ | 领地的唯一标识名称，仅支持英文、数字和下划线 |

创建成功后，你将收到包含领地坐标和面积的系统提示。

[!NOTE]
领地名称创建后**不可修改**，请在创建前仔细考虑命名。建议使用有意义的英文名称，例如 `farm_area`、`redstone_lab` 等。

## 权限系统

Dominion 提供了精细的权限控制体系，可针对不同操作分别设置权限。

### 权限类型一览

| 权限节点 | 说明 | 默认值（主人） | 默认值（访客） |
| :--- | :--- | :---: | :---: |
| `build` | 放置方块 | ✅ 允许 | ❌ 拒绝 |
| `break` | 破坏方块 | ✅ 允许 | ❌ 拒绝 |
| `interact` | 交互（门、按钮、拉杆等） | ✅ 允许 | ❌ 拒绝 |
| `container` | 打开容器（箱子、漏斗等） | ✅ 允许 | ❌ 拒绝 |
| `use` | 使用物品（食物、弓箭等） | ✅ 允许 | ✅ 允许 |
| `attack` | 攻击实体（怪物、动物） | ✅ 允许 | ✅ 允许 |
| `teleport` | 传送到领地内 | ✅ 允许 | ✅ 允许 |
| `move` | 在领地内移动 | ✅ 允许 | ✅ 允许 |
| `tnt` | 点燃/放置TNT | ✅ 允许 | ❌ 拒绝 |
| `fire` | 使用打火石/火焰 | ✅ 允许 | ❌ 拒绝 |
| `explosion` | 爆炸破坏方块 | ✅ 允许 | ❌ 拒绝 |
| `monster_spawn` | 怪物自然生成 | ✅ 允许 | ✅ 允许 |
| `animal_spawn` | 动物自然生成 | ✅ 允许 | ✅ 允许 |

### 设置权限命令

```
/dominion set <权限节点> <true/false> [玩家名]
```

| 参数 | 必填 | 说明 |
| :--- | :---: | :--- |
| `<权限节点>` | ✅ | 如 `build`、`break`、`interact` 等 |
| `<true/false>` | ✅ | `true` 允许，`false` 拒绝 |
| `[玩家名]` | ❌ | 指定玩家。省略则设置所有访客的默认权限 |

## 信任玩家

信任玩家是领地管理的核心功能。被信任的玩家可以获得领地主人授予的特定权限。

### 信任相关命令

| 命令 | 语法 | 说明 |
| :--- | :--- | :--- |
| 信任玩家 | `/dominion trust <玩家名>` | 将玩家加入领地信任列表 |
| 取消信任 | `/dominion untrust <玩家名>` | 将玩家从领地信任列表移除 |
| 查看信任列表 | `/dominion trustlist` | 查看当前领地的所有信任玩家 |

[!TIP]
信任玩家后，建议立即使用 `/dominion set <权限> <true/false> <玩家名>` 为该玩家精确分配所需权限，避免给予过多权限造成安全隐患。

## 旗帜（Flags）

旗帜是领地级别的全局开关，用于控制领地内的特定行为。

### 常用旗帜

| 旗帜名称 | 说明 | 默认值 |
| :--- | :--- | :---: |
| `pvp` | 是否允许玩家间战斗 | `false` |
| `mob_griefing` | 是否允许怪物破坏方块 | `false` |
| `fire_spread` | 火焰是否蔓延 | `false` |
| `lava_flow` | 岩浆是否流动 | `true` |
| `water_flow` | 水是否流动 | `true` |
| `leaf_decay` | 树叶是否自然消失 | `true` |
| `snow_form` | 是否积雪 | `true` |
| `ice_form` | 是否结冰 | `true` |
| `crop_growth` | 农作物是否生长 | `true` |

### 设置旗帜命令

```
/dominion flag <旗帜名称> <true/false>
```

[!WARNING]
旗帜修改会影响整个领地范围内的所有玩家（包括领地主人）。修改前请确认了解该旗帜的作用范围。例如，关闭 `crop_growth` 将导致领地内所有农田无法生长。

## 红石机器与容器保护

Dominion 对红石机器和容器提供了全面的保护机制，这是一秋小镇服务器中最重要的功能之一。

### 容器保护

以下方块被视为容器，受 `container` 权限控制：

| 方块类型 | 包含内容 |
| :--- | :--- |
| 箱类 | 木箱、大箱子、末影箱 |
| 漏斗类 | 漏斗、投掷器、发射器 |
| 熔炉类 | 熔炉、高炉、烟熏炉 |
| 其他 | 炼药台、酿酒店、桶、潜影盒 |

没有 `container` 权限的玩家**无法打开**以上任何容器，也无法从中取出或放入物品。

### 红石保护

| 保护对象 | 说明 |
| :--- | :--- |
| 红石粉 | 非成员无法破坏或放置红石粉线路 |
| 中继器/比较器 | 受 `build`/`break` 权限保护 |
| 活塞 | 活塞的推出方块行为受领地边界限制 |
| 红石火把/灯 | 受 `build`/`break` 权限保护 |
| 按钮/拉杆 | 受 `interact` 权限保护，未授权玩家无法操作 |
| 压力板 | 受 `interact` 权限保护 |
| 唱片机/钟/信标 | 受 `interact` 权限保护 |

[!NOTE]
活塞推出方块的行为不会超出领地边界。即使红石信号试图驱动活塞将方块推出领地外，该操作也会被系统阻止。这确保了你的红石装置不会影响邻近领地。

## 常见问题

**Q: 我的领地可以和别人的领地重叠吗？**

A: 不可以。Dominion 不允许领地之间出现重叠。如果选定的区域与已有领地冲突，系统会提示你调整范围。

**Q: 退出服务器后领地还会存在吗？**

A: 是的。领地数据保存在服务器端，即使你离线，领地保护依然生效。

**Q: 如何创建子领地？**

A: 在已有领地内部使用木斧选定更小的矩形区域，然后执行 `/dominion create <子领地名称>` 即可。子领地可以拥有与父领地不同的权限配置。

[!TIP]
子领地非常适合用于划分公共区域和私人区域。例如，你可以在商店领地中创建一个子领地作为仓库，仅允许自己进入。
