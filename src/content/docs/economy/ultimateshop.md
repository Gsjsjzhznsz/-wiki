# UltimateShop 全局商店

UltimateShop 是一秋小镇服务器上的**管理员维护的全局 GUI 商店**。与玩家自主创建的 QuickShop 箱子商店不同，UltimateShop 由管理团队统一配置商品和价格，为全体玩家提供一个稳定、可靠的物品买卖平台。

[!NOTE]
UltimateShop 中的商品和价格由管理员设定，通常参考服务器经济平衡性进行调整。如果你认为某些物品的定价不合理，欢迎通过社区反馈渠道提出建议。

---

## 与玩家商店的区别

| 对比维度 | UltimateShop（全局商店） | QuickShop-Hikari（玩家商店） |
----------|------------------------|---------------------------|
| 管理者 | 服务器管理员 | 普通玩家 |
| 商品来源 | 管理员配置，**无限供应** | 玩家自行补货，**数量有限** |
| 价格 | 固定定价，由管理员统一调整 | 玩家自由定价，随市场波动 |
| 可靠性 | 始终在线，不会缺货 | 可能缺货，需要玩家维护 |
| 交互方式 | GUI 菜单点击 | 箱子悬浮物品框点击 |
| 交易对手 | 系统（货币进出由系统吸收/发放） | 其他玩家（P2P 交易） |
| 适用场景 | 购买基础物资、出售收集物 | 玩家间自由交易、稀有物品买卖 |

[!TIP]
**最佳策略**：优先使用 UltimateShop 购买基础物资和出售常见收集物，在 QuickShop 玩家商店中寻找稀有物品或更优惠的价格。两者配合使用，经济效率最高。

## 打开商店

| 命令 | 别名 | 说明 |
|------|------|------|
| `/shop` | `/ushop`, `/us` | 打开全局商店 GUI |
| `/shop <分类>` | — | 直接打开指定分类页面 |

执行命令后，会弹出一个 GUI 界面，包含所有可用的商品分类。

## 商品分类

UltimateShop 的商品按类别组织，方便快速查找。以下是服务器当前启用的分类（以实际游戏内为准）：

| 分类图标 | 分类名称 | 包含内容 |
----------|----------|----------|
| 🪨 | 方块类 | 常见建筑方块（石头、木头、玻璃等） |
| ⚔️ | 武器与工具 | 剑、镐、锄、锹等工具及武器 |
| 🧪 | 红石材料 | 红石粉、中继器、比较器、活塞等 |
| 🌾 | 农业与食物 | 小麦、胡萝卜、马铃薯、牛排等 |
| 💎 | 矿物与宝石 | 铁锭、金锭、钻石、绿宝石等 |
| 🧪 | 药水与酿造 | 玻璃瓶、地狱疣、烈焰粉等 |

[!NOTE]
作为红石服务器，**红石材料**分类是一秋小镇 UltimateShop 中使用最频繁的分类之一。管理团队会确保红石基础材料始终有合理的买卖价格。

## 购买物品

1. 使用 `/shop` 打开商店 GUI。
2. 点击进入所需分类。
3. 浏览商品列表，每个商品格子显示：
   - **物品图标及名称**
   - **购买价格**（绿色文字）
   - **出售价格**（红色文字，如果支持回收）
   - **库存状态**（全局商店通常为无限）
4. **左键点击**商品即可购买 1 个。
5. **Shift + 左键**可购买一组（64 个）。
6. 确认购买后，金币自动从 XConomy 账户扣除。

[!WARNING]
购买前请确认背包有足够空间。如果背包已满，购买会失败但不扣款。

---

## 出售物品

部分商品支持出售（回收）功能。如果你的背包中有可回收的物品：

1. 打开 `/shop` 并进入对应分类。
2. 可回收的商品会显示**红色出售价格**。
3. **右键点击**商品即可出售 1 个。
4. **Shift + 右键**可出售背包中所有同类物品。
5. 出售后金币自动存入你的 XConomy 账户。

[!TIP]
出售物品时，系统会优先出售你快捷栏中的物品，然后是背包中的物品。合理整理背包可以让出售更高效。

## 与 XConomy 的集成

UltimateShop 通过 Vault 接口与 XConomy 无缝对接：

- **购买操作**：调用 `economy.withdrawPlayer()` 扣除玩家余额。
- **出售操作**：调用 `economy.depositPlayer()` 增加玩家余额。
- **余额不足时**：交易自动取消，并提示「余额不足」。
- **交易日志**：所有交易记录可在服务器后台查询，便于经济审计。

## 常见问题

**Q: UltimateShop 的价格会变动吗？**
A: 会。管理团队会根据服务器经济状况定期调整价格。重大价格调整会提前在社区公告。

**Q: 为什么某些物品只能买不能卖？**
A: 出于经济平衡考虑，部分物品不开放回收功能，防止玩家通过系统无限刷钱。

**Q: 能否在商店中搜索物品？**
A: 可以在 GUI 顶部的搜索栏中输入物品名称进行搜索。支持中英文搜索。

**Q: 全局商店和玩家商店哪个更划算？**
A: 视情况而定。全局商店价格稳定但可能不是最低；玩家商店价格灵活，有时能找到更优惠的折扣。建议两者对比后再决定。
