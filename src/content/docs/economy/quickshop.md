# QuickShop-Hikari 玩家商店

QuickShop-Hikari 是一秋小镇服务器上**玩家间自由交易**的核心插件。每个玩家都可以创建属于自己的箱子商店，出售自己多余的物资，或者购买他人出售的物品。所有交易金额通过 Vault 接口自动经由 XConomy 处理。

[!NOTE]
QuickShop-Hikari 是一秋小镇经济生态中最活跃的组成部分。一个繁荣的玩家商店区意味着活跃的社区经济，鼓励大家多多开设商店！

---

## 创建商店

创建一个玩家商店非常简单，只需以下几个步骤：

### 步骤一：放置箱子

首先，放置一个**箱子（Chest）**。这个箱子将作为商店的物品存储容器。

[!TIP]
建议使用**双箱子（大箱子）**以获得更多存储空间。放置时先放一个箱子，再在其旁边放置第二个箱子即可自动合并。

### 步骤二：手持物品

将你想要出售或收购的物品**放在主手**（快捷栏中选中的物品）。

### 步骤三：执行创建命令

手持物品后，**对着箱子潜行并右键**（默认行为），或者使用命令：

```
/qs create <价格>
```

例如，你想以每个 10 金币的价格出售钻石：

1. 手持钻石
2. 对着箱子潜行右键，或执行 `/qs create 10`

创建成功后，箱子上方会出现一个悬浮的物品展示框，显示物品、价格及商店类型。

## 商店类型

QuickShop-Hikari 支持两种商店类型：

| 类型 | 说明 | 悬浮显示颜色 | 适用场景 |
|------|------|-------------|----------|
| **出售商店（Selling）** | 从箱子中出售物品给其他玩家 | 绿色 | 出售多余资源 |
| **收购商店（Buying）** | 从其他玩家手中收购物品到箱子 | 蓝色 | 收集特定材料 |

创建商店后，你可以使用以下命令切换类型：

| 命令 | 说明 |
|------|------|
| `/qs sell` | 切换为出售模式（将箱子内物品卖给他人） |
| `/qs buy` | 切换为收购模式（从他人手中收购物品存入箱子） |

[!TIP]
**出售模式**下，你需要先将要出售的物品放入箱子里。**收购模式**下，箱子需要有足够的空位存放收购来的物品。

## 定价策略

合理的定价是商店成功的关键。以下是一些参考建议：

| 物品类别 | 建议出售价范围（金币/个） | 说明 |
|----------|------------------------|------|
| 常见矿物（铁锭、金锭） | 5 ~ 20 | 基础资源，需求大但供应充足 |
| 钻石 | 30 ~ 80 | 高价值矿物，参考全局商店价格 |
| 绿宝石 | 20 ~ 50 | 村民交易相关，有稳定需求 |
| 红石相关（红石粉、中继器等） | 5 ~ 50 | 一秋小镇是红石服务器，需求旺盛 |
| 末影珍珠 | 50 ~ 150 | 末地资源，获取成本较高 |
| 稀有物品（鞘翅、海洋之心） | 500+ | 根据市场行情自定 |

[!WARNING]
请勿恶意定价（如天价收购空箱子来套取他人金币）。管理员会定期巡查商店区，发现异常定价的商店将被强制关闭。

## 买卖操作

### 购买物品（从其他玩家的出售商店买）

1. 找到你想购买的商店（悬浮物品框显示绿色）
2. 直接**左键点击**悬浮物品框
3. 系统自动从你的 XConomy 账户扣除对应金额
4. 物品直接进入你的背包

### 出售物品（卖给其他玩家的收购商店）

1. 找到收购商店（悬浮物品框显示蓝色）
2. 手持要出售的对应物品
3. **左键点击**悬浮物品框
4. 系统自动将金币存入你的 XConomy 账户

[!NOTE]
如果你背包已满，购买操作会被取消，但不会扣款。请确保背包有足够空间。

## 商店管理命令

以下是商店拥有者常用的管理命令：

| 命令 | 别名 | 说明 |
|------|------|------|
| `/qs create <价格>` | — | 创建商店 |
| `/qs remove` | — | 移除你脚下的商店 |
| `/qs price <价格>` | — | 修改商店价格 |
| `/qs amount <数量>` | — | 设置每次交易的数量 |
| `/qs sell` | — | 切换为出售模式 |
| `/qs buy` | — | 切换为收购模式 |
| `/qs info` | — | 查看商店详细信息 |
| `/qs empty` | — | 查看你所有已售空的商店 |
| `/qs fetch` | — | 收取商店产生的收入（如配置了延迟结算） |
| `/qs staff <玩家>` | — | 添加商店员工，允许他人补货 |
| `/qs unlimited` | — | 切换无限模式（管理员专用） |

## 与 XConomy 的集成

QuickShop-Hikari 通过 Vault 接口与 XConomy 深度集成：

1. **购买时**：买家的 XConomy 余额减少，卖家的 XConomy 余额增加。
2. **出售时**：收购方的 XConomy 余额减少，出售方的 XConomy 余额增加。
3. **交易记录**：所有交易均记录在 XConomy 的日志中，管理员可追溯异常交易。
4. **余额校验**：每次交易前，QuickShop-Hikari 会通过 Vault 查询买家/收购方余额，余额不足时交易自动取消。

## 常见问题

**Q: 创建商店时提示「你没有权限」？**
A: 请确认你已放置了箱子，并且手持了要交易的物品。如果仍无法创建，请检查你所在的区域是否允许放置容器。

**Q: 商店显示「已售空」怎么办？**
A: 出售商店需要你手动往箱子里补充对应物品。你可以在箱子里存放大量物品，商店会自动从中扣除已售出的部分。

**Q: 其他人能打开我的商店箱子吗？**
A: 不能。QuickShop-Hikari 会保护商店箱子，只有商店拥有者和被授权的员工（通过 `/qs staff` 添加）才能打开。

**Q: 如何找到其他玩家的商店？**
A: 服务器设有专门的**商业区**，你可以在商业区内浏览各玩家的商店。也可以通过 `/qs find <物品>` 搜索出售特定物品的商店。
