# ExoShopkeepers NPC 商店

ExoShopkeepers 是一秋小镇服务器上的 **NPC 商店插件**，允许管理团队创建自定义 NPC 商人。NPC 商店以实体 NPC 的形式存在于游戏世界中，玩家通过与 NPC 交互来浏览和进行交易，提供比箱子商店更直观、更沉浸的交易体验。

[!NOTE]
ExoShopkeepers NPC 商店通常放置在服务器主城、商业区及重要交通节点。它们由管理员创建和维护，为玩家提供便捷的定点交易服务。

---

## NPC 商店的优势

与 QuickShop 箱子商店和 UltimateShop GUI 商店相比，NPC 商店具有以下独特优势：

| 优势 | 说明 |
|------|------|
| **沉浸感强** | NPC 以实体形式存在，交互方式最接近原版村民交易 |
| **定点服务** | 固定位置，玩家无需记命令，直接走过去点击即可 |
| **自定义外观** | NPC 可设置名称、皮肤、朝向等，融入建筑风格 |
| **分类明确** | 每个 NPC 可专注某一类商品，交易界面简洁 |
| **防恶意破坏** | NPC 不会被破坏、不会被偷，比箱子商店更安全 |
| **支持复杂交易** | 支持以物易物（物品换物品）等非纯金币交易 |

[!TIP]
在一秋小镇的**红石主题**下，部分 NPC 专门出售红石组件和相关材料，方便红石玩家快速补货。

---

## 如何使用 NPC 商店

作为普通玩家，使用 NPC 商店非常简单：

1. **找到 NPC**：前往主城或商业区，寻找带有名称标签的 NPC。
2. **右键点击 NPC**：打开交易 GUI 界面。
3. **浏览商品**：在 GUI 中查看可购买的物品和价格。
4. **完成交易**：左键点击购买，金币自动从 XConomy 账户扣除。

NPC 商店交互流程与原版村民交易类似，上手零门槛。

---

## 交易界面说明

NPC 商店的交易 GUI 通常包含以下元素：

| GUI 区域 | 说明 |
|----------|------|
| **顶部信息栏** | 显示 NPC 名称和商店标题 |
| **商品格子** | 每个格子显示一个可购买的商品、数量和价格 |
| **翻页按钮** | 商品较多时，底部提供上一页/下一页按钮 |
| **购买操作** | 左键单击购买 1 个，Shift+左键购买一组 |

[!NOTE]
部分 NPC 可能同时支持**购买和出售**。出售操作通常为右键点击商品格子。

## 管理员：创建 NPC 商店

以下是管理员创建和管理 NPC 商店的相关命令（仅管理员可用）：

| 命令 | 说明 |
|------|------|
| `/exoshopkeeper create <名称>` | 在脚下创建一个新 NPC 商店 |
| `/exoshopkeeper edit <NPC>` | 编辑指定 NPC 的商品列表 |
| `/exoshopkeeper remove <NPC>` | 移除指定 NPC |
| `/exoshopkeeper rename <NPC> <新名称>` | 修改 NPC 显示名称 |
| `/exoshopkeeper move <NPC>` | 移动 NPC 到当前脚下位置 |
| `/exoshopkeeper skin <NPC> <皮肤名>` | 更改 NPC 的皮肤 |
| `/exoshopkeeper trade add <NPC>` | 为 NPC 添加新交易项 |
| `/exoshopkeeper trade remove <NPC> <交易ID>` | 移除指定交易项 |

### 设置交易项

添加交易项时，管理员需要配置以下参数：

| 参数 | 说明 | 示例 |
|------|------|------|
| **出售物品** | NPC 卖给玩家的物品及数量 | 钻石 x1 |
| **价格类型** | 金币价格或以物易物 | 50 金币 / 绿宝石 x10 |
| **购买物品**（可选） | NPC 从玩家手中收购的物品 | 铁锭 x32 |
| **购买价格**（可选） | 收购时给予玩家的金币 | 15 金币 |

[!WARNING]
NPC 商店的经济设置直接影响服务器经济平衡。管理员在调整 NPC 商品和价格前，应充分评估对经济体系的影响。

## NPC 自定义选项

ExoShopkeepers 支持丰富的 NPC 自定义功能，让每个 NPC 都能融入一秋小镇的世界：

| 自定义项 | 说明 | 示例 |
|----------|------|------|
| **名称** | NPC 头顶的显示名称 | `§b红石材料商` |
| **皮肤** | NPC 的外观皮肤 | 使用自定义皮肤或预设皮肤 |
| **朝向** | NPC 面朝的方向 | 朝向道路、朝向商店入口 |
| **动作** | NPC 的闲置动作 | 站立、挥手、挖掘等 |
| **位置** | NPC 放置的精确坐标 | 通常放置在建筑内部或门口 |

## 与 XConomy 的集成

与 QuickShop-Hikari 和 UltimateShop 一样，ExoShopkeepers 通过 Vault 接口与 XConomy 对接：

- **购买时**：从玩家的 XConomy 账户扣除对应金币。
- **出售（回收）时**：向玩家的 XConomy 账户存入对应金币。
- **以物易物**：直接在玩家与 NPC 之间交换物品，不涉及金币。
- **余额校验**：购买前自动检查玩家余额，余额不足时交易取消。

## 常见问题

**Q: NPC 商店和 UltimateShop 有什么区别？我该用哪个？**
A: NPC 商店和 UltimateShop 的商品均由管理员配置，区别在于**交互方式**。NPC 商店通过世界中的 NPC 交互，更直观；UltimateShop 通过命令打开 GUI，随时随地可用。建议就近使用 NPC 商店，远程使用 `/shop`。

**Q: NPC 被方块挡住了怎么办？**
A: 请联系管理员，使用移动命令将 NPC 重新放置到合适位置。

**Q: 我能自己创建 NPC 商店吗？**
A: 目前 NPC 商店仅限管理员创建。如果你想开店，请使用 QuickShop-Hikari 创建玩家箱子商店。

**Q: NPC 商店支持以物易物吗？**
A: 支持。管理员可以配置「用 A 物品交换 B 物品」的交易，无需经过金币。这类交易在 NPC 商店中非常实用。
