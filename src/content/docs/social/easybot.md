# EasyBot 机器人

> EasyBot-2.4.0 | 一秋小镇的智能服务器机器人

EasyBot 是一秋小镇服务器中部署的智能机器人系统。它可以在服务器内模拟一个虚拟玩家，提供自动回复、自定义命令执行等功能，为社区带来更多互动乐趣和便利。

## 📋 功能概览

| 功能 | 说明 |
| :--- | :--- |
| 自动回复 | 当玩家在聊天中提及机器人名称时，机器人会自动回复预设内容 |
| 自定义命令 | 机器人可以执行预设的自定义命令，提供快捷功能 |
| 定时消息 | 可设置定时广播，由机器人发送重要通知 |
| 新手引导 | 自动向新加入的玩家发送欢迎消息和基础引导信息 |
| 玩家互动 | 支持与玩家进行简单的互动对话 |
| 管理辅助 | 可配合管理团队执行部分自动化管理任务 |

## 🤖 自动回复系统

EasyBot 的核心功能之一是自动回复。当玩家在聊天中 @机器人 或直接与其对话时，机器人会根据预设的规则自动回应。

### 自动回复触发规则

| 触发方式 | 说明 | 示例 |
| :--- | :--- | :--- |
| 关键词匹配 | 聊天消息中包含特定关键词时触发 | 玩家发送「服务器规则」触发回复 |
| @提及 | 使用 `@机器人名` 直接提及机器人 | `@Bot 你好` |
| 私聊 | 直接私聊机器人 | `/msg Bot 帮助` |
| 正则匹配 | 使用正则表达式匹配复杂模式 | 匹配「IP 地址」「链接」等敏感内容 |

### 预设回复示例

以下是一秋小镇中 EasyBot 的一些常见自动回复场景：

| 关键词 | 机器人回复内容 |
| :--- | :--- |
| `规则` / `server rule` | 发送服务器规则摘要和详细规则页面链接 |
| `帮助` / `help` | 列出常用命令和 Wiki 链接 |
| `签到` | 提示玩家使用 `/litesignin` 进行每日签到 |
| `商店` | 提示商店相关操作指引 |
| `领地` | 提供领地相关命令帮助 |

[!TIP]
如果你是新手玩家，可以在聊天中直接发送「帮助」来获取机器人的自动回复指引。机器人会为你提供服务器常用功能的快速入门信息。

## 📝 自定义命令

EasyBot 支持自定义命令功能，管理员可以为机器人配置特殊命令，使玩家通过与机器人交互来执行特定操作。

### 可用的机器人命令

| 命令 | 说明 | 使用示例 |
| :--- | :--- | :--- |
| `/bot <消息>` | 向机器人发送消息 | `/bot 你好` |
| `/bot help` | 查看机器人帮助信息 | `/bot help` |
| `/bot info` | 查看机器人状态和信息 | `/bot info` |

### 管理员命令

| 命令 | 说明 | 权限 |
| :--- | :--- | :--- |
| `/easybot reload` | 重新加载机器人配置 | `easybot.admin` |
| `/easybot addreply <关键词> <回复>` | 添加自动回复规则 | `easybot.admin` |
| `/easybot delreply <关键词>` | 删除自动回复规则 | `easybot.admin` |
| `/easybot listreply` | 列出所有自动回复规则 | `easybot.admin` |
| `/easybot toggle` | 开启/关闭机器人 | `easybot.admin` |

[!NOTE]
机器人的自动回复内容和管理命令仅对拥有管理员权限的玩家可见和可操作。普通玩家只能与机器人进行预设的互动对话。

## 🌟 对社区的帮助

EasyBot 在一秋小镇社区中扮演着重要的辅助角色：

### 新手引导
- 新玩家首次进入服务器时，机器人会自动发送欢迎消息
- 提供基础操作指引，降低新手学习成本
- 引导玩家查看 Wiki 获取更详细的信息

### 信息查询
- 玩家可以随时通过机器人快速查询常用信息
- 减少管理员重复回答相同问题的负担
- 24 小时在线，随时为玩家提供帮助

### 社区氛围
- 通过趣味性的自动回复增加社区互动性
- 定时发送有趣的小知识或提示
- 配合节日活动发送特别消息

### 运营辅助
- 定时提醒玩家签到、参与活动等
- 在维护或更新时自动广播通知
- 协助管理团队传达重要信息

## ⚙️ 配置说明

EasyBot 的配置文件位于 `plugins/EasyBot/config.yml`，管理员可以在此文件中进行详细配置。

### 基本配置项

| 配置项 | 说明 | 默认值 |
| :--- | :--- | :--- |
| `bot-name` | 机器人的显示名称 | `Bot` |
| `enabled` | 是否启动机器人 | `true` |
| `auto-reply-enabled` | 是否启用自动回复 | `true` |
| `welcome-message` | 新玩家欢迎消息 | （自定义内容） |
| `cooldown` | 回复冷却时间（秒） | `5` |

[!WARNING]
管理员在修改 EasyBot 配置时，请确保回复内容符合服务器规范。修改配置后需要使用 `/easybot reload` 命令重载配置才能生效。建议在修改前备份原始配置文件。
